# 00 制作环境与工具链

这一章说明整部片子是在什么机器、什么软件、什么模型上做出来的，AI 编程助手怎样把这些工具串成一条流水线，以及全片共用的几条约定（帧率、画幅、片长、色板、宣纸纹理、命名、目录）。后面各章提到的脚本和路径，都以这里的约定为准。

文中的路径都写成相对工程根目录 `~/Movies/ZAFU2` 的形式（例如 `work/v16k/edit18.py`）；工程之外的目录写完整的 `~/...` 路径。

## 0.5 两个在线生成服务

### 0.5.1 Codex CLI：版画关键帧

所有木刻版画关键帧都由 Codex CLI 调用内置的 GPT 图像生成完成。批处理脚本 `codex/run_batch.py` 用系统 `python3` 运行（`python3 codex/run_batch.py <批次名> --par <并行数>`）：它读作业文件 `codex/jobs/<批次名>.json`（一个 JSON 数组，每项一张图，字段有输出名 `id`、参考图 `refs`、每张参考图的用途 `labels`、提示词 `prompt`、画幅 `aspect`，以及 `keep_text`、`transparent` 两个开关），为每个作业在 `codex/work/<id>/` 里起一个 `codex exec` 进程，参考图按顺序成为 Image 1、Image 2……，提示词前后自动加上统一的开头和禁止项；生成的 PNG 存为 `codex/out/<id>.png`，作业本身存为同名 `.json`，已有的输出会跳过。命令行参数、提示词的拼接规则、作业 JSON 的完整格式和关键帧从照片到版画的全过程见[第 2 章](02_照片变成版画关键帧.md)。

### 0.5.2 LibTV MCP：AI 视频

AI 视频用 LibTV 的 Seedance 2.5 模型生成，由 AI 编程助手通过 LibTV 提供的 MCP 接口直接下单：每段用两张版画关键帧做首帧和尾帧，参数固定为 16:9、720p、不生成声音、每次只生成 1 条，时长按镜头需要取 5 到 10 秒。生成的视频是 1280x720、24 fps、无音轨，统一下载到 `libtv_jobs/out/<编号>.mp4`。成片用到 16 段（AI-1、O1、AI-G、S1 到 S4、E2、S7、T1b、AI-4、AI-5、AI-7 到 AI-10），每段只生成一次，合计生成 111 秒。每段的提示词、首尾帧、检查结论（可用区间、瑕疵）都记在 `libtv_jobs/queue.json`。具体做法见[第 3 章](03_AI视频_Seedance.md)。

## 0.6 DaVinci Resolve Studio 与脚本入口

最终的装配全部在 DaVinci Resolve Studio 21.1 里完成，工程名 `ZAFU_68_v16`。时间线不是手工拖出来的，而是由脚本 `work/v16k/build_resolve.py` 按 `renders/v18/elements/plan.json` 自动搭建：

- 这个脚本要在 Resolve 自己的 Python 环境里执行（那里预先提供了 `resolve` 对象）。AI 编程助手通过 DaVinci Resolve 的 MCP 接口把一段 Python 送进 Resolve 执行；手工复现时也可以在 Resolve 的“工作区 > 控制台”里选 Py3 执行同样的代码。
- 入口代码只做一件事：准备几个全局变量，然后执行 `build_resolve.py`：

```python
import os
g = dict(resolve=resolve,
         EL=os.path.expanduser('~/Movies/ZAFU2/renders/v18/elements'),
         TL_NAME='R13_装配_v5_1',
         AUDIO=os.path.expanduser('~/Movies/ZAFU2/audio/v3/out/v23/stereo'),
         BIN_SUFFIX='_v5_1', END=110.0, NO_PAGE=True)
exec(open(os.path.expanduser('~/Movies/ZAFU2/work/v16k/build_resolve.py')).read(), g)
```

各变量的含义：`EL` 是素材目录（里面有 plan.json），`TL_NAME` 是要新建的时间线名，`AUDIO` 是四条分轨所在目录，`BIN_SUFFIX` 是媒体池文件夹名的后缀（每次装配一套独立的文件夹），`END` 是宣纸纹理层请求的长度（秒；实际覆盖范围见 0.8.4），`NO_PAGE=True` 让 31.4 秒的接缝保持 plan.json 里的重印转场（脚本里另有一个翻页叠加层的分支，成片不用）。轨道结构、输出设置和交付见[第 8 章](08_达芬奇装配输出与检查.md)。

## 0.7 AI 编程助手怎样驱动整条流水线

整部片子由运行在这台 Mac 上的 AI 编程助手（Claude Code）执行。它的工作方式可以归纳成五类动作：

1. **写脚本并运行**：剪辑、导出、转场、配音处理、音效设计、作曲、混音都是 Python 脚本，由它写好后在对应的环境里运行（画面用 `.venv_ai/bin/python`，声音用 `~/Movies/ZAFU/.venv/bin/python`）。耗时长的导出放到后台运行，输出写进 `renders/v18/logs/` 等日志文件。
2. **调用 Codex CLI**：通过 `codex/run_batch.py` 批量生成版画关键帧。
3. **调用 LibTV MCP**：上传首尾帧、提交 Seedance 2.5 任务、查询状态、下载成片。
4. **调用 DaVinci Resolve 的脚本接口**：执行 `build_resolve.py` 搭时间线、设置输出、启动渲染、导出 .drt / .drp。
5. **检查**：用脚本测量（跳变扫描 `work/v16k/scan_jumps.py`、接缝联络表 `work/v18/join_sheet.py`、响度、清晰度、位移），再把联络表、截帧等图片直接打开来看，确认后才进入下一步。

所有时间、文字和转场参数都写在脚本里，不在图形界面里手工调整。这样任何一处改动都可以从脚本重新生成，达芬奇时间线也可以随时按 plan.json 重建。

## 0.8 全片通用约定

### 0.8.1 时间、帧率、片长

| 约定 | 数值 | 依据 |
|---|---|---|
| 帧率 | 25 fps（全片所有中间素材、时间线、成片） | `work/v16k/edit18.py` 第 23 行 `W, H, FPS = 1920, 1080, 25`；`plan.json` 的 `"fps": 25` |
| 片长 | 110.0 秒 = 2750 帧 | `edit18.py` 第 24 行 `END = 110.0`；成片视频流 2750 帧 |
| 成片容器时长 | 110.08 秒 | AAC 音轨 5160 帧 x 1024 / 48000 = 110.08 秒（编码器的前后补齐），画面仍是 2750 帧 |
| 时间单位 | 所有脚本用“片中秒”（浮点数）；换算帧号一律 `round(t x 25)` | `build_resolve.py` 的 `fr = lambda t: int(round(t * FPS))` |
| 素材手柄（handle：镜头入出点之外多留的余量） | 每个镜头素材前后各多导出 0.6 秒 | `export18.py` 的 `HANDLE = 0.6` |
| AI 视频源帧率 | 24 fps，按时间映射重采样到 25 fps | `export18.py` 的 AI 分支 |
| 声音 | 48 kHz；分轨 32 位浮点，母带 24 位 | `audio/v3/mix_final.py` |

### 0.8.2 画幅与像素格式

- Python 里所有画面都按 1920x1080 计算，内部是 0 到 1 的浮点 RGB（显示参考值，按 Rec.709 / sRGB 理解）。
- 代码镜头和转场导出为 ProRes 422 HQ（`yuv422p10le`，由 16 位 RGB 编码）；字幕层导出为带透明通道（alpha）的 ProRes 4444。
- AI 镜头导出时保持 1280x720 原始像素，只做重定时，放大交给达芬奇（媒体池里对代码镜头和 AI 镜头都开 2 倍超级缩放 Super Scale）。
- 达芬奇时间线是 3840x2160、25 fps，渲染输出 1920x1080。
- 宣纸纹理层是 3840x2160 的 PNG。
- 成片交付 1920x1080、25 fps、H.264（High，约 11.7 Mb/s）+ AAC 320 kb/s、48 kHz 立体声；综合响度 -16.0 LUFS，真峰值（dBTP，包括采样点之间的峰值）-2.2 dBTP。另用 ffmpeg 做了 8D 双耳版和 960x540 的手机预览版（[第 8 章](08_达芬奇装配输出与检查.md)）。

### 0.8.3 色板

全片是一套“江南水印木刻”的色彩：宣纸底色加四种颜料。定义在 `tools/woodblock2.py`：

| 名称 | RGB（0 到 1） |
|---|---|
| 宣纸 PAPER | 0.935, 0.905, 0.835 |
| 墨 ink | 0.17, 0.155, 0.14 |
| 石青 blue | 0.40, 0.52, 0.66 |
| 石绿 green | 0.47, 0.63, 0.49 |
| 赭石 ochre | 0.85, 0.58, 0.33 |

这组常数由 `work/v16k/scenes.py` 导入，成片里用到的是纸色：`paper()` 把宣纸纹理的平均色归一到 PAPER，代码镜头里的纸都是这个颜色。关键帧的版式工具 `tools/woodblock.py` 用一组相近的颜料值（[第 2 章](02_照片变成版画关键帧.md) 2.3.2），Codex 的提示词描述颜色时也用这四种颜料（ink、mineral blue、mineral green、ochre）。

全片统一的色调来自关键帧本身的四色版画和竹子镜头的专门调色（`work/v18/bamboo_look.py`，[第 4 章](04_代码镜头竹林与three.js.md)）；导出脚本和达芬奇时间线上都不套用调色 LUT（颜色查找表）。

### 0.8.4 宣纸纹理

宣纸纹理有两层用途，来源是同一张图：

1. **底图 `data/v14/paper.png`**（2048x1152）：程序生成的暖色宣纸，低频斑驳（fBm 分形噪声，5 个八度）、细颗粒、2600 根随机纤维，底色 (0.925, 0.893, 0.828)，随机种子 3。代码镜头里凡是“纸”（拼贴卡片的纸边、重印转场里洗掉画面后露出的纸、片尾的底色）都从它取。
2. **覆盖层 `renders/v18/elements/paper_4k.png`**（3840x2160）：把底图放大到 4K，再除以它自己 60 像素的高斯模糊，只留下纤维细节、整体变平，乘 0.985。在达芬奇里放在最上面的视频轨 V5，混合模式“正片叠底”，不透明度 35%。`build_resolve.py` 请求从第 0 帧铺到第 2750 帧，但 Resolve 导入静帧的默认长度是 5 秒，请求的长度被截到素材长度，所以成片里这一层只覆盖 0 到 5.0 秒（125 帧）。纹理很淡，5 秒处没有可见的跳变（[第 8 章](08_达芬奇装配输出与检查.md)）。

这两步都是一次性的内联脚本，没有单独的文件，代码附在本章末尾。

### 0.8.5 字体

### 宣纸纹理底图 `data/v14/paper.png`

在任一装有 numpy、scipy、Pillow 的环境里，于工程根目录运行：

```python
# a warm rice-paper texture (2048x1152): low-frequency mottling, fine grain, long fibres
import numpy as np
from PIL import Image
from scipy.ndimage import gaussian_filter, zoom
rng = np.random.default_rng(3)
W, H = 2048, 1152
def fbm(scale, oct=5):
    out = np.zeros((H, W)); a = 1.0; tot = 0
    for o in range(oct):
        s = max(2, int(scale / 2 ** o))
        n = rng.random((H // s + 2, W // s + 2))
        n = zoom(n, s, order=3)[:H, :W]
        out += a * n; tot += a; a *= 0.5
    return out / tot
mott = fbm(256) - 0.5
grain = gaussian_filter(rng.random((H, W)) - 0.5, 0.7)
fib = np.zeros((H, W))
for k in range(2600):
    x, y = rng.random() * W, rng.random() * H; ang = rng.normal(0.3, 0.9); L = rng.integers(20, 120)
    t = np.arange(L)
    xs = (x + np.cos(ang) * t + np.cumsum(rng.normal(0, 0.3, L))).astype(int) % W
    ys = (y + np.sin(ang) * t + np.cumsum(rng.normal(0, 0.3, L))).astype(int) % H
    fib[ys, xs] += rng.random() * 0.8
fib = gaussian_filter(fib, 0.6)
base = np.array([0.925, 0.893, 0.828])          # warm xuan paper
v = 1 + mott * 0.06 + grain * 0.035 - fib * 0.05
img = np.clip(base[None, None, :] * v[..., None], 0, 1)
Image.fromarray((img * 255).astype(np.uint8)).save('data/v14/paper.png')
```

### 4K 纤维覆盖层 `paper_4k.png`

用 `.venv_ai` 在工程根目录运行：

```python
import numpy as np, cv2
from PIL import Image
p = np.asarray(Image.open('data/v14/paper.png').convert('RGB'), np.float32) / 255
p = cv2.resize(p, (3840, 2160), interpolation=cv2.INTER_CUBIC)
lo = cv2.GaussianBlur(p, (0, 0), 60); fib = p / np.maximum(lo, 1e-3)    # keep only the fibre detail, flat overall
out = np.clip(0.985 * fib, 0, 1)
Image.fromarray((out * 255 + 0.5).astype(np.uint8)).save('renders/v18/elements/paper_4k.png')
```
