# 04 代码镜头、竹林引擎与 three.js

成片里有一类镜头不是 AI 视频生成的，而是由程序逐帧算出来的：开场的小星球、今天的校门、竹林、"一草一木"拼贴、天目山与小岛、木化石、研究图版、森林、校训金字、片尾生日贺卡，以及叠在树苗长大那段上的三维落叶。本章逐个说明它们用什么输入、哪个脚本哪个函数、什么参数、输出什么文件、怎么检查。片尾生日贺卡（Title19）单独写在[第 6 章](06_片尾_校庆生日贺卡.md)。

所有脚本由 AI 编程助手（Claude Code）在作者的 Mac（Apple M3 Max，128 GB）上编写和运行。下文路径都相对于工程根目录 `~/Movies/ZAFU2`，竹林引擎相对于 `~/Movies/ZAFU`。

### 1.3 代码之间的调用关系

`edit18.py` 不是孤立的脚本，它按顺序加载上一层的镜头表并复用其中的工具：

- `work/v16k/edit18.py` 加载 `work/v16k/edit17.py`（第 20 行），edit17 加载 `work/v16k/edit16.py`，edit16 加载 `work/v14/edit14.py`、`work/v16k/scenes.py`、`work/v16k/planet.py`；edit14 加载 `work/v14/comp.py`，comp 再加载 `work/v14/paper.py`。`scenes.py` 还从 `tools/woodblock2.py` 取颜料和纸色常量。
- 代码镜头用到的共享工具：`comp.py` 里的 `glyph_row`（排一行字）、`over`（带透明度合成）、`ease`（平滑缓动 x²(3-2x)）、`ramp`（线性 0 到 1）、`out_cubic`；`paper.py` 里的 `Ink`（2 倍超采样的墨线）；`scenes.py` 里的 `paper()` 和 `Parallax`。
- 字体：`comp.py` 第 15 行指定思源宋体可变字重版 `data/fonts/NotoSerifSC[wght].ttf`，代码镜头里的小字全部用它。

## 二、代码镜头怎么导出、怎么进达芬奇

### 2.1 导出

导出脚本是 `work/v16k/export18.py`。它先执行 `edit18.film()` 拿到镜头表，再把每个不是 AI 视频的镜头逐帧算出来，编码成 ProRes：

- 时间范围：镜头本身 [a, b] 前后各加 `HANDLE = 0.6` 秒手柄（handle：镜头起止点之外多导出的一段画面，第 17 行），并裁在 0 到 110 秒内。手柄让转场时两侧画面都在动。
- 编码（第 21 到 24 行）：输入 16 位 `rgb48le`，`prores_ks -profile:v 3`（ProRes 422 HQ），`yuv422p10le`，25 fps，1920x1080。
- 输出：`renders/v18/elements/shots/S<编号>_<类名>.mov`，同时在 `renders/v18/elements/plan.json` 里记一条 `kind: "code"`，写明 `a`、`b`、`file_start`、`file_end`。

在工程根目录运行（导出全部代码镜头）：

```bash
.venv_ai/bin/python work/v16k/export18.py shots
```

只重导某几个镜头时加 `only=编号`，编号就是上表的数字，例如只导片尾：

```bash
.venv_ai/bin/python work/v16k/export18.py shots only=26
```

想先在 Python 里预览某一段（含文字，不经达芬奇），可以直接运行镜头表，参数是起止秒和输出文件：

```bash
.venv_ai/bin/python work/v16k/edit18.py 42.0 48.9 renders/v18/preview_bamboo.mov
```

### 2.2 进达芬奇

`work/v16k/build_resolve.py` 在 DaVinci Resolve 的脚本环境里读 plan.json，把每个代码镜头放到 V1 轨：入点 = a 减 file_start，录制位置 = a（第 93 到 100 行）；所有画面素材设 `Super Scale = 2`（达芬奇自带的 2 倍超分辨率放大，第 60 行）；V5 轨铺一张宣纸纹理 `paper_4k.png`，正片叠底、不透明度 35%（第 130 行）。转场文件放在 V2、V3。装配和输出的细节见[第 8 章](08_达芬奇装配输出与检查.md)。

## 三、共用的积木

### 3.1 宣纸底色 `paper()`

`work/v16k/scenes.py` 第 28 到 32 行：读 `data/v14/paper.png`（2048x1152），缩放到 1080p，再按通道除以自身均值、乘以纸色 `PAPER = (0.935, 0.905, 0.835)`（来自 `tools/woodblock2.py` 第 19 行）。结果是一张保留纤维纹理、整体色温统一的暖白宣纸，拼贴和片尾都铺在它上面。

### 3.2 静帧版画的匀速推移 `Parallax18`

`edit18.py` 第 345 到 366 行。它继承 `scenes.py` 的 `Parallax`，但有三处关键差别：

1. **匀速**：进度 `u = t_local / dur`，不做缓入缓出，并允许在 -0.4 到 1.4 之间外推。这样镜头在叠化进来时已经在动，叠化出去时还在动，手柄里也继续动。
2. **不按深度逐像素推**：成片里所有静帧都没有给深度图，深度恒为 0.5，于是公式里的视差项 `shift * (d - 0.5)` 为 0，整张画面作为一个整体做"推近 + 平移"，物体边缘不会被拉扯变形。
3. **2 倍超采样**：先把版画用 Lanczos 放大到 3840x2160，在 2 倍尺寸上用 `cv2.remap`（双线性）做变换，再用 `INTER_AREA` 缩回 1920x1080。慢速亚像素移动时，木刻细线不会一帧清楚一帧糊而"闪"。

每帧的变换（2 倍空间里，W=1920、H=1080）：

```
z  = 1 + dz * u
sx = (x - W) / z + W - dx * u * 2
sy = (y - H) / z + H - dy * u * 2
```

`move = (dx, dy, dz)`：dx、dy 是整段移动的像素数（按 1080p 计，正值使画面内容向右、向下移），dz 是整段推近的比例。

`frame(t_local, img=...)` 还能传入一张"已经合成好东西的版画"，让它和版画一起按同一个运动走（校训金字就是这样做的，见 4.9）。

### 3.3 浮尘、光点与远处落叶 `Motes`

`edit18.py` 第 312 到 328 行。参数 `Motes(n, seed, color, size, vel, area, alpha, leaves)`：

- 用固定种子 `seed` 生成 n 个点，深度 `z = r²`（大多数在远处）；速度 `vel * (0.4 + z)`、半径 `size[0] + (size[1] - size[0]) * z`、亮度 `0.35 + 0.65 z` 都随深度变，近的大、快、亮。
- 位置 `x = x0 + vx t + 14 sin(φ + t(0.7 + z))`、`y = y0 + vy t`，超出画面就绕回。
- 用 `cv2.circle` 以 1/16 像素精度（`shift=4`）画在一张单通道层上，再高斯模糊 σ=2，所以运动没有阶梯感。
- 合成：光点模式按"滤色"叠加 `img + (1 - img) * 层 * 颜色`；`leaves=True` 时按普通透明度盖上去 `img * (1 - 层) + 颜色 * 层`，看起来是远处飘落的金色叶片。

### 3.4 光柱 `rays`

`edit18.py` 第 331 到 342 行：从 `origin` 以 `angle_deg`（0 为竖直向下）射出 n 条光柱，每条是垂直于光柱方向的高斯带（宽度 `width * U(0.5, 1.6)`，强度 `U(0.4, 1.0)`，横向位置随机），沿光柱方向乘以 `clip(along / 0.9H)^0.6 * exp(-along / 1.6H)` 让它渐起渐消。在 1/4 分辨率上计算后放大，返回 0 到 1 的蒙版。

### 3.5 薄雾带 `MistBand`

`edit18.py` 第 613 到 629 行：在 1/4 分辨率上生成两层高斯模糊噪声（σ=14 占 0.7，σ=6 占 0.3）组成分形噪声，放大到 (W+600)xH；纵向乘一条高斯带 `exp(-((y - y_c) / y_s)²)`；每帧按 `vx` 像素每秒横向取窗（亚像素插值）；透明度 `带 * (0.55 + 0.45 tanh(噪声)) * strength`，颜色是暖纸白 (0.95, 0.93, 0.88)。它是一层不需要抠图的"前景"，用来给整体推移的版画加纵深。

## 四、逐个镜头

### 4.1 S00 小星球开场（0.0 到 5.6 秒）

**画面**：天目山水墨版画卷成一颗小星球，在宣纸上缓缓转动，镜头从第一帧就开始推近；约 2.7 秒起星球展开、曲率变为零，推近加速成俯冲；5.6 秒最后一帧正好是平铺的版画，也就是下一个 AI 镜头 AI-1 的第一帧，直接切过去。画面右侧的竖排问句"一粒种子会如何成长？"在文字层里。

**输入**：`libtv_jobs/out/AI-1_f0.png`，即 AI-1.mp4 解码出的第 0 帧（1280x720，逐像素一致）；`data/v14/paper.png`。

**脚本**：`work/v16k/planet.py` 的 `Planet` 搭场景，`edit18.py` 第 369 到 405 行的 `Planet18` 定运动。

**做法**：

1. **全景卷轴**（planet.py 第 22 到 37 行）：版画放大到 1920x1080，与左右镜像拼成 3840 宽、首尾无缝的卷轴；从版画左下角 [740:1080, 0:620] 取一块密林，横竖镜像拼成无缝贴图，铺 1500 行接在卷轴下方，作为星球的"内部"。
2. **卷曲映射**（planet.py 第 38 到 51 行 `warp`）：屏幕坐标反算回卷轴坐标。曲率 k=1 时卷轴底边围成一圈（半径 `Wp / 2πk`，Wp=3840），k=0 时平铺。星球外面的像素填宣纸。
3. **推近曲线**（Planet18 第 377 到 379 行）：缩放取对数后用三次 Hermite 样条 `CubicHermiteSpline`，节点时间 [0, 3.3, 5.6]，取值 [ln(0.76 s_p), ln(s_p), 0]，斜率 [0.05, 0.14, 0.30]（每秒对数缩放）。其中 `s_p = 0.42 H / (Wp/2π + H) ≈ 0.268`，即整颗星球占画高 42%。缩放从约 0.204 起、3.3 秒到 0.268、5.6 秒到 1，单调、无停顿。
4. **展开**（第 393 到 400 行）：`x = ramp(t, 2.7, 5.6)`，`u = 2.5x² - 1.5x³`（缓起，结束时仍保留约三分之一的峰值速度），曲率 `k = (1 - u)^1.6`；自转偏移 `spin = -260 (1 - u)² t` 像素，在版画铺平的同时正好停稳，切点处没有横移。
5. **与 AI-1 衔接**（第 380 到 387 行）：2.6 秒以后每帧取 t-0.005、t、t+0.005 三个子帧平均，带上和 AI 镜头相近的运动模糊；4.9 到 5.6 秒逐渐加一点反锐化（高斯 σ=1.2，增益到 1.24），让平铺版画的清晰度和 AI-1 自己的帧一致。
6. **手柄**（第 389 到 392 行）：5.6 秒以后返回平铺版画，按每秒 0.30 的对数速度继续推近，正是交给 AI-1 的速度。

**输出**：`S00_Planet18.mov`，0.0 到 6.2 秒（开头没有手柄），155 帧。

### 4.2 S08 今天的校门（24.0 到 27.4 秒）

### 4.4 S14 一草一木拼贴（52.5375 到 55.95 秒）

**画面**：东湖校区的航拍（AI-4）缩小成第一张卡片落在宣纸上，画面仍在动；接着四张植物版画（荷花、银杏、雪中红叶、雪中梅花）依次从右、左、下、右滑入，每张不透明，带一圈纸边和柔和投影，正好落在配乐的拍子上。

**脚本**：`edit18.py` 第 558 到 590 行 `Plants18`；镜头表第 1018 行。

**节拍**：`beat(k) = 48.3 + k * (59.6 - 48.3) / 16`（第 979 行），也就是配乐里 48.3 到 59.6 秒之间的 16 拍（配乐的拍点表见[第 7 章](07_声音.md)）。拼贴从 beat(6) = 52.5375 秒开始，四张卡片的落点是 beat(7) 到 beat(10)：53.244、53.950、54.656、55.363 秒。

**参数**：

- 第一张（航拍）：`base_fn = ai4.frame`，即 AI-4 镜头本身继续播放（V1 上 AI-4 在 52.5375 秒直接切到本镜头，画面连续）。`u0 = ease(ramp(t, 52.5375, 53.1375))`，缩放 `(1 - 0.11 u0)(1 - 0.04 × 已落下张数)`，旋转 `-1.0° u0 - 0.6° × 已落下张数`。"已落下张数"是平滑计数：每张卡在落点前 0.4 秒内从 0 缓到 1。
- 四张植物卡：`kf('K_plant_lotus')`、`K_plant_ginkgo`、`K_plant_redleaf_snow`、`K_plant_blossom_snow`（`codex/out/` 下的 Codex 版画）。每张在落点前 0.6 秒从画外整张滑入（方向 `[(1,0), (-1,0), (0,1), (1,0)]`，起点偏移 1.02 W 或 1.05 H），`ease` 缓动；缩放 `0.93 (1 - 0.04 × 后面已落下的张数)`；旋转 `±(3.0° (1 - v) + 1.0° × 后落张数)`，单双张方向相反。
- 卡片外观（`_card`，第 565 到 573 行）：13x13 膨胀出一圈宣纸色纸边；投影 = 卡片加纸边蒙版高斯模糊 σ=16，向下 12、向右 9 像素，压暗 30%；卡片本身完全不透明，任何一帧都不会出现两张画互相透出的重影。
- 底纸：`scenes.py` 的 `paper()`。

**输出**：`S14_Plants18.mov`，51.9375 到 56.55 秒，115 帧。进入时没有转场（AI-4 与本镜头前半段是同一画面），离开用雪光转场 T10_light。

### 4.5 S15 天目山彩色版画、S16 鹿鸣岛夏景（55.95 到 59.6 秒）

两个短镜头，只有整张推移：

## 五、竹林：GLSL 竹林引擎

"像一株竹，坚韧不拔，不断超越"这一句（42.6 到 48.3 秒）用的是 `~/Movies/ZAFU` 工程里自研的 GLSL 渲染引擎（片元着色器光线步进：显卡对每个像素沿视线一步步前进，找到与场景的交点再着色）：竹笋破土而出，镜头随它穿过毛竹林一路上升，表现竹子快速生长。`~/Movies/ZAFU` 本身是一部完整的 GLSL 渲染影片，本片只取其中的竹林镜头：用这个引擎渲染一段无字、无颗粒、16:9 的竹林，再在本片里按运动量变速、调成版画色。

### 5.1 引擎结构（`~/Movies/ZAFU`）

| 文件 | 作用 |
|---|---|
| `engine.py` | 渲染器。moderngl 建 OpenGL 4.1 离屏上下文；每帧在半个快门内取 K 个子帧（Halton 抖动，同时用于景深）累加，得到运动模糊；再做 7 级辉光、横向光晕、最终调色、文字层；读回 16 位，经 ffmpeg 写 ProRes 422 HQ。 |
| `edl.py` | 该工程整部影片的镜头表、转场、调色关键帧、相机路径。竹林相关：`SHOTS` 第 21 行 `('bamboo', HIT1, HIT1 + 17.1, 6)`，`TRANS` 第 28 行，调色关键帧第 39 行，相机 `BAMBOO_CAM` 第 137 行，`bamboo_uniforms` 第 157 行。 |
| `edl_v3b.py` | 导入 edl.py，并覆盖两项设置：画幅 16:9（`uAspect = 1.7778`，不加黑边）、颗粒 `uGrain = 0`。 |
| `timeline.py` | 90 BPM、每小节 80 帧的时间表；`T['bamboo'] = bar(8) = 21.333` 秒。 |
| `shots.py`、`camera.py` | 全屏片元着色器镜头类；Catmull-Rom 相机路径（时间、机位、目标点、视场角、光圈）。 |
| `shots/bamboo.glsl` | 竹林场景本身（411 行），`shots/common.glsl` 是共用噪声与工具函数。 |
| `post/post.glsl` | 后期各个通道：累加、转场合成、辉光上下采样、光晕、最终调色（ACES 拟合曲线、白平衡、饱和度、对比度、暗角、颗粒、黑边）、文字。 |
| `textgen.py`、`shot_roots.py`、`shot_light.py`、其余 `shots/*.glsl` | 该工程其他镜头和文字。渲染竹林时它们也会被加载（edl.py 初始化时编译所有镜头），但画面里只出现竹林。 |

### 5.2 竹林场景里有什么（`shots/bamboo.glsl`）

- **竹秆**：1.3 米网格，每格 80% 概率有一根毛竹，半径 4.2 到 8.2 厘米、轻微倾斜、竹节间距 0.30 到 0.44 米，竹节处有凸起和白粉带；光线先与（斜）圆柱求交，再在精确距离场上走几步，网格遍历找最近的竹秆。
- **主角竹笋**：在原点，高度由 `uHeroH` 控制，顶端有层层笋箨（褐色斑点、细毛逆光发亮），幼笋基部更粗；破土瞬间地面裂开、扬起尘土和碎屑。
- **竹冠与光**：12 到 18.5 米之间是体积化的竹冠，阳光穿过竹冠的透过率逐步积分，形成林间光柱，光柱里有闪烁的尘埃；地面有落叶。
- **镜头穿过竹冠**：`uLeaves` 大于 0 时叠三层竹叶，从画面掠过。
- **景深**：用子帧抖动做薄透镜景深，光圈随相机路径从 0.006 收到 0。

镜头参数（`edl.py`）：

- 相机路径 `BAMBOO_CAM`（局部时间，机位，目标点，视场角，光圈）：0.0 秒 (1.05, 0.30, 0.85) 看 (0, 0.42, 0)，48°，0.006；2.5 秒 (1.25, 0.95, 0.55)，50°；6.0 秒 (1.45, 3.40, -0.35)，52°；10.5 秒 (1.00, 7.60, -1.25)，54°；14.5 秒 (0.30, 11.8, -1.55)，56°；17.1 秒 (-0.2, 15.6, -1.20) 看 (1.2, 18.5, 3.0)，58°，0。`frame_left(…, 0.34)` 把目标点向右偏，让竹笋落在画面左三分之一。
- `bamboo_uniforms`：破土 `burst = 1 - (1 - t/0.5)³`；竹高 `uHeroH = 0.22 + 0.5 burst + 0.98 max(0, t - 0.5) + 0.25 S(0.5, 3.0, t)`（S 为五次平滑阶跃），即破土后约每秒长高 1 米；竹叶掠过 `uLeaves = S(15.0, 16.3, t)`。
- 调色关键帧（21.3 秒起，晨光）：`uTemp 0.25`，`uSat 1.12`，`uBloomAmt 0.14`，`uHalation 0.4`，`uVignette 0.35`，高光 (0.08, 0.04, -0.06)，阴影 (-0.04, 0.02, 0.03)；其余用 `GRADE_DEFAULT`（对比度 1.04、色差 0.012 等）。
- 采样：竹林镜头每帧 K=6 个子帧（与上一镜头重叠的几帧取 8），快门 0.5 帧。


- 输出：`~/Movies/ZAFU/renders/v18_bamboo.mov`，ProRes 422 HQ，`yuv422p10le`，1920x1080，30 fps，513 帧，17.1 秒。

### 5.4 进入成片：`Bamboo` 类

`edit18.py` 第 674 到 719 行。

1. **读帧**：用 OpenCV 按帧号定位读取，BGR 转 RGB。
2. **测运动**（`_motion`，第 697 到 706 行）：DIS 光流（光流是逐像素估计相邻两帧之间的运动；DIS 是 OpenCV 里的一种快速光流算法，这里用 ULTRAFAST 预设）在 480x270 灰度图上逐帧计算，每帧取光流幅度的第 90 百分位，结果存在 `work/v18/motion.json` 的 `v18_bamboo` 条目里（513 个值，已有就直接读）。
3. **按运动量变速**（第 687 行）：源区间 0.45 到 16.0 秒（15.55 秒）压进 5.7 秒的镜头位置，平均约 2.7 倍速。`motion_map(..., p=0.55, floor=2.0, smax=4.2, smin=1.0, start_slow=0.8)`：每个源帧分到的影片时间正比于 `max(运动, 2.0)^0.55`，用 σ=0.35 秒的高斯平滑，播放速度限制在 1.0 到 4.2 倍之间，开头 0.6 秒额外放慢（`start_slow`）。实际速度：破土处约 2.1 倍，攀升中段最快约 3.5 倍（约 45.6 秒），结尾回到约 2 倍。`motion_map` 函数在第 105 到 123 行。
4. **帧间混合**：源时间落在两帧之间且小数部分大于 0.05 时，两张调好色的帧线性混合。镜头后的手柄按结束速度继续走，最多到倒数第二帧；镜头前的手柄停在源文件 0.45 秒那一帧，正好被林间光转场最亮的部分盖住。
5. **版画化调色**（`work/v18/bamboo_look.py` 的 `look`，第 4 到 20 行），每帧：
   - 亮度先乘 1.08；
   - 按亮度做渐变映射：暗部墨绿 (0.10, 0.17, 0.14) 到中间调石绿 (0.42, 0.57, 0.31)（亮度 0 到 0.45），再到金色 (0.86, 0.74, 0.46)（0.45 到 0.8），再到纸白 (0.94, 0.90, 0.80)（0.8 到 1）；
   - 原图降到 78% 饱和度；最终 = 45% 渐变映射 + 55% 降饱和原图；
   - 刻线：亮度高斯模糊 σ=1.2 后求 Sobel 梯度，`clip((梯度 - 0.10) / 0.25) × 0.35` 作为墨线强度，向暗部墨绿混合，让三维竹子带一点木刻的轮廓线。
6. **衔接**：进入是林间光转场（T07_light，枫树的金光漫开，竹林从光里长出），离开是水墨晕开（T08_ink）接图书馆俯瞰。

**输出**：`S12_Bamboo.mov`，42.0 到 48.9 秒，172 帧。

## 六、three.js：树苗长大时掠过镜头的落叶

### 6.1 用途和位置

树苗长成大树的 AI 镜头 T1b（37.8 到 42.6 秒）里，季节变换有两处颜色跳变。用两阵从镜头前刮过的槭叶和翅果把它们盖住：

- 叠加层 `libtv_jobs/fx/out/FX_T1b_leaves.mov`：ProRes 4444，带透明通道，1920x1080，25 fps，44 帧；
- 时间线位置：第 987 帧起（39.48 秒）到第 1030 帧（41.20 秒，含），由 `build_resolve.py` 第 21 行 `OVERLAYS = [(…FX_T1b_leaves.mov, 987, 44)]` 指定；
- 两阵风的峰值在本层第 11 帧和第 32 帧附近，实测峰值覆盖率约 94% 和 92%，两阵之间约 28%，首尾两帧完全透明。

为了让这层落叶和底下的画面对得上，T1b 在镜头表里按线性速度播放（`edit18.py` 第 998 行，`p=0.0`），源区间 0.3 到 9.6 秒映射到 37.8 到 42.6 秒。

### 6.2 页面结构（`libtv_jobs/fx/page/`）

- `index.html`：透明背景的空页面，用 import map 把 `three` 指到本地的 `../vendor/three.module.js`（r186）。
- `main.js`：离线渲染外壳。读 URL 参数 `fx`、`w`、`h`、`K`、`shutter`；`WebGLRenderer`（抗锯齿、透明、预乘 alpha（颜色值已经乘过透明度），输出色彩空间为线性直写）；`window.renderFrame(i)` 把第 i 帧在 `[i - shutter/2, i + shutter/2]` 内均匀取 K 个子帧，`gl.readPixels` 读回后平均，得到运动模糊；第一帧和最后一帧只取一个精确样本，保证与切点逐像素一致；结果以 base64 返回。
- `t1b_leaves.js`：效果本身。

### 6.3 落叶效果的参数（`t1b_leaves.js`）

- 帧数 `N = 44`；两阵风 `GUSTS = [{c: 11.2, n: 600}, {c: 32.2, n: 640}]`，共 1240 个实例；透视相机视场角 45°，16:9，相机在原点看向 -z；随机数种子 20261018（mulberry32 式整数哈希）。
- 每个实例：46% 概率是"近处"（z 在 -0.95 到 -2.45 个场景单位，基础尺寸 0.30 到 0.64，13 到 20 帧横穿画面），其余是"远处"（z 在 -2.6 到 -9.1，基础尺寸 0.16 到 0.32，22 到 36 帧横穿）；叶片尺寸再乘一个 0.8 到 1.2 的随机系数。远处的 12% 是翅果（尺寸 0.10 到 0.18，飞行中多下落约 0.4 个半画高）。每片叶子穿越画面的时间以所属那阵风的峰值为中心随机错开。从画面左外侧飞到右外侧，带上下起伏，绕随机轴翻转、绕自身旋转，并有小幅抖动。
- 颜色取自 T1b 画面：秋色金、橙、橙红、黄五种，绿色三种，翅果两种稻草色；第一阵 82% 秋色，第二阵 55% 秋色。
- 形状全部在片元着色器里用数学函数画：槭叶是五个裂片（高斯瓣叠加）、锯齿边、短叶柄、五条主脉；翅果是一粒种子加一片带纹的翅。
- 虚化：近处叶片的边缘软化宽度 `clamp((2 + z) × 0.04 + 0.028, 0.018, 0.07)`，远处固定 0.010，即近虚远实。
- 版画式着色：受光面和背光面两级亮度（0.82），叶脉压暗 24%，边缘带一点逆光暖色，饱和度保留 90%，再加细微的纸纹颗粒。
- 透明度：每片叶子在穿越的前 8% 和后 10% 渐入渐出；整层在第 0 到 4 帧淡入、第 39 到 43 帧淡出。
- 混合：`RawShaderMaterial`，GLSL3，预乘 alpha（ONE, ONE_MINUS_SRC_ALPHA），不写深度。

### 6.4 渲染与编码

在 `libtv_jobs/fx` 下运行。`render.mjs` 用 playwright-core 启动本机 Chrome（无头，`--use-angle=metal`），通过请求拦截直接读本地文件（不开服务器），逐帧调用 `renderFrame`，把原始 RGBA 存为 `out/t1b_leaves/raw/00000.rgba` 等：

```bash
node render.mjs t1b_leaves --w 1920 --h 1080 --K 24 --shutter 0.35
```

`post.py` 把原始帧上下翻转、从预乘 alpha 转成直通 alpha，存 PNG：

```bash
python post.py png t1b_leaves 1920 1080 --alpha
```

再编码成带透明通道的 ProRes 4444（`prores_ks -profile:v 4444 -pix_fmt yuva444p10le -alpha_bits 16`，25 fps）：

```bash
python post.py prores t1b_leaves FX_T1b_leaves --alpha
```

### 6.5 放进时间线

`build_resolve.py` 把 `FX_T1b_leaves.mov` 导入"转场"素材夹，设 `Alpha mode = Straight`（第 62 到 64 行），放在 V2、V3 中这段时间空闲的一条上（第 120 到 123 行）。第 987 到 1030 帧之间 V2 没有转场，所以落叶层在 V2 轨，在字幕层之下、画面之上。

### 6.6 检查

- `libtv_jobs/fx/comp.py` 把原始帧叠到背景帧上拼成联络表，背景是 T1b 在这 44 帧的画面（`libtv_jobs/fx/data/T1b/bg_000.png` 到 `bg_043.png`）。用法是 `python comp.py <fx> <背景目录> <宽> <高> <输出.jpg> <帧号…>`，例如看两阵风的峰值：

```bash
python comp.py t1b_leaves data/T1b 1920 1080 out/t1b_peaks.jpg 0 11 21 32 43
```

- 在成片里核对：39.9 秒和 40.75 秒，叶片覆盖处与 T1b 素材差异很大（平均约 50 个色阶），叶片之外差异很小，说明叠加层确实在成片里且位置正确。

## 七、文字层不在镜头里

所有字幕、竖排题字（开场问句、"博览古今""学参天地"）和片尾的"本片部分画面由人工智能辅助生成"都不画进代码镜头，而是由 `export18.py overlay` 单独渲染成一条全长的透明文字层 `renders/v18/elements/overlay_text.mov`（ProRes 4444）。做法是每帧把所有文字分别画在纯黑和纯白底上：`alpha = 1 - (白底结果 - 黑底结果)`，`颜色 = 黑底结果 / alpha`（第 148 到 160 行），这样文字的柔边和发光都能正确地以透明度叠到任何画面上。字幕的对时见[第 1 章](01_文案配音与时间表.md)，样式见[第 5 章](05_剪辑与镜头处理.md)。

## 八、检查方法

| 检查什么 | 怎么查 |
|---|---|
| 镜头是否就是成片里的画面 | 在成片中取帧与导出文件同一时刻的帧比较。11 个代码镜头的相关系数都在 0.96 到 1.00 之间，平均差 2 到 4 个色阶（来自 V5 宣纸纹理的正片叠底和 H.264 压缩）。 |
| 静帧推移会不会闪 | 逐帧计算画面中部的拉普拉斯方差（清晰度）。木化石、校门、森林、小岛、校训石逐帧变化的中位数在 0.11% 到 0.22%。推移进度 u 恰好为 0 的那一帧是恒等采样，会比相邻帧锐约 11%，这些帧都落在手柄或转场里。 |
| 金字会不会相对石头抖动 | 字先刻进版画再一起推，同一次重采样；成片里测得金字相对石头的残余抖动约 0.02 像素。 |
| 有没有突跳 | `work/v16k/scan_jumps.py`：逐帧算与上一帧的平均差（1/4 尺寸灰度）和平均颜色的跳变，远高于局部水平（大于 0.06 且大于 3.5 倍局部中位数加 0.01）或颜色跳变大于 0.045 的帧列出来。 |
| 接缝顺不顺 | `work/v18/join_sheet.py`：每个接缝取 -0.6、-0.36、-0.12、0、+0.12、+0.36、+0.6 秒七帧排成一行，所有接缝拼成一张联络表逐个看。 |
| 竹林色调 | `bamboo_look.py` 直接运行时，取源文件第 40、160、400 帧，左原图右调色后并排输出对照图。 |

扫描命令示例（对成片；`renders/v18/R13_v5_1_1080p.mp4` 是达芬奇渲染出的 1080p 成片，见[第 8 章](08_达芬奇装配输出与检查.md)）：

```bash
.venv_ai/bin/python work/v16k/scan_jumps.py renders/v18/R13_v5_1_1080p.mp4
```
