# 07 声音：配音处理、配乐、音效、8D 与混音

成片的声音全部由 Python 脚本生成，最后以四条分轨进入达芬奇：A1 旁白（DX）、A2 配乐（MX）、A3 音效（FX）、A4 环境声（AMB）。同一套素材出两版母带：立体声版（扬声器、普通耳机）和 8D 双耳版（戴耳机听的三维声）。全程 48 kHz，中间文件为 32 位浮点 WAV。

本章按制作顺序写：先说明声音引擎，再作曲与渲染配乐，准备配音素材，用 CLAP（LAION 发布的声音与文字对比学习模型，可以用一句文字描述去检索声音）扫描音效库挑素材，做音效设计（立体声和双耳两套），最后混音、进达芬奇、交付与检查。

### 0.3 声音引擎的工作方式（eng.py、snd.py）

后面所有步骤都用这套引擎，先说清楚它怎么工作：

- **对象**：每个声音是一个对象：一段单声道片段（点声源）或立体声片段（床），一个起始时间，一个在听者处的电平，一个方向（可以是随时间变化的路径：秒、方位角、距离、仰角），一个混响发送量。
- **四条分轨**：每个对象属于 DX、MX、FX、AMB 之一。
- **场景混响**：用真实脉冲响应（Apple 脉冲响应库，路径 /Library/Audio/Impulse Responses/Apple，Apple 软件许可协议）。B 格式（四声道 W X Y Z）的脉冲响应会被解码到输出布局，混响从四周包围听者。
- **立体声布局**：恒定功率声像，方位 ±60° 及以外为硬左右；身后的声音折回同侧并降 1.5 dB。
- **双耳布局（bin）**：每个对象经 Apple HRTF 放在三维空间里，详见第 6 节。
- **取素材**：snd.py 的 S(名字, a, b) 按名字从音效库索引里找到文件，用 ffmpeg 解码成 48 kHz 浮点缓存，截取 a 到 b 秒。speed(x, r) 用重采样做“磁带变速”，r > 1 变快变高，用来把铃声移到 D 调。
- **限幅器**：snd.limiter() 是前视 4 ms 的峰值限幅器，峰值按 4 倍过采样估计（接近真峰值），1 ms 一块计算增益，释放 150 ms。

## 1. 配乐：程序作曲（score_zafu_v10.py）

### 1.1 作曲方法

配乐不是在音序器里手弹，而是用 Python 写音符。score_zafu_v10.py 开头 exec 读入 score_lib_v13_head.py（主题、和声、各种写法函数），写完全部音符后再 exec 读入 score_lib_v13_writer.py（写 MIDI 和检查报告）。

- **调性**：D 大调（D = 2，主音在第 4 八度，即 D4 = MIDI 62）。
- **一条主旋律**：一句 16 小节的长句，分四个乐句，乐句之间用弱起音衔接，不在长音上停：
  - P1 问：和声 I、vi、IV I/3、Vsus V，落在五级音上；
  - P2 答：I、IV、I/3 ii、I，落在三音上（还没说完）；
  - P3 攀升：IV、V、vi、Vsus V，一个音型逐级模进到顶点，落在属和弦；
  - P4 回归与终止：I、IV、I/5 V7、I，全片唯一的完全终止。
- **写法函数**（score_lib_v13_head.py）：
  - mel()：在某个乐器上从某拍开始奏主题，长音下自动加三度或六度，乐句顶点加高八度；
  - prog()：罗马数字和声进行变成和弦表；
  - lh()：钢琴左手，分解和弦（八分音符：根音、五音、十度……）或“held”柱式和弦；
  - pad()：弦乐等长音铺底，声部按最近距离进行（voiced()）；
  - tutti()：全奏铺底；held()：保持和弦；swell()：渐强渐弱的发夹（表情控制器 CC11）。
- **配器规则**（写在代码里）：
  - 不用竖琴、钢片琴、木琴类，不用定音鼓滚奏（竖琴声部 harp、定音鼓 timp 都是 0 个音）；
  - 钢琴左手的柱式和弦三个音同时按下，不做琶音式滚奏（滚奏听起来像竖琴）；
  - 每个长音都有渐强；弦乐声部按最近音进行；钢琴双手演奏；
  - 人性化：随机数种子 1958，每个音的时间随机偏移 ±10 ms，力度随机 ±2.5。
- **钉在画面上的速度图**：Cue 类把“拍”换算成“影片秒”，锚点直接取画面时间。乐句边界前后时间略拉宽 0.035 s（rub=0.035），像乐手在句尾呼吸。

## 2. 配乐：采样渲染与厅堂混音

整个配乐流程由一条命令完成：

```bash
bash music/render_v10.sh
```

render_v10.sh 依次运行四步（SCORE_DIR 和 SCORE_OUT 都设为 music/score_v10）：作曲 → 逐声部渲染干声 → 厅堂立体声混音 → 3D 双耳混音。

### 2.1 逐声部渲染干声（render_score.py）

- **钢琴**：Salamander 三角钢琴（Yamaha C5 录音，16 层力度，FreePats 整理的 SF2 版本 SalamanderGrandPiano-V3+20200602.sf2；SF2 即 SoundFont 采样乐器格式；许可 CC BY 3.0，原始采样作者 Alexander Holm），用 FluidSynth 渲染：增益 0.7，48 kHz，关闭 FluidSynth 自带混响与合唱，复音数 512，24 位 WAV。
- **其他声部**：Sonatina Symphonic Orchestra 的分组录音（SFZ 格式，即用文本描述采样映射的乐器格式；许可 Creative Commons Sampling Plus 1.0，原作者 Mattias Westlund），用 sso.py 这个小型 SFZ 播放器渲染（支持力度层、cc1 力度交叉淡化、循环、包络、轮换采样）。每个声部对应的 SFZ：

## 3. 配音素材

配音为配音员的真人录音（vo/zwt/zwt11.mp3，解码为 vo/zwt/zwt11.wav：48 kHz 单声道，103.13 s）。整段录音按句切成 18 句（u01 到 u18），每句的起点、时长、语音起点记录在 vo/audition/zwt_timing.json，整段录音另存为 vo/audition/zwt_full.wav（zwt11.wav 的 32 位浮点副本；切句方法见[第 1 章](01_文案配音与时间表.md)）。

片尾最后一句“浙江农林大学 生日快乐”是补录的，共 6 段（vo/bday/b1 到 b6，48 kHz 单声道）。选用第 4 段：它的语气与正片配音的结尾最接近（中位音高 176 Hz，正片录音里同一位置的句子为 164 Hz），“生日快乐”明显上扬。同一人的 6 段不叠用（叠在一起会产生相位重叠的怪声）。

### 3.1 补录句的音色匹配

补录和正片不是同一次录音，音色有差别。按正片结尾三句的平均频谱做 70% 的匹配：

1. **参考频谱**：取正片录音 zwt_full.wav 中最后三句（u16、u17、u18）的区间，算长时平均频谱（LTAS：librosa STFT（短时傅里叶变换），n_fft 4096，hop 1024，只取能量高于中位数的帧）。
2. **补录频谱**：b4.wav 的 1.6 到 5.2 s，同样算 LTAS。
3. **差值**：参考减补录，减去 300 到 3000 Hz 的平均差（只比形状，不比音量）。
4. **平滑与限幅**：按 1/3 倍频程平滑；只在 80 Hz 到 12 kHz 内修正，其余为 0；限制在 ±4 dB；再乘 0.7（70% 匹配）。
5. **滤波**：用 firwin2 设计 2047 个抽头的 FIR 滤波器，与整段 b4 卷积（fftconvolve，same 模式）。
6. **截句**：取 1.62 到 5.45 s（语音起点 1.67 s 之前 0.05 s，到最后一个音节后 0.35 s），共 3.83 s；开头 20 ms 淡入，结尾 250 ms 淡出。
7. **拼接**：在 zwt_full.wav 末尾加 0.5 s 静音，接上这句，再加 0.5 s 静音，写成 vo/audition/zwt2_full.wav（48 kHz 浮点单声道，107.96 s）。
8. **时间表**：zwt2_timing.json 与 zwt_timing.json 相同，只把 u18 改为：起点 103.631 s（在 zwt2_full.wav 内），时长 3.83 s，两个分句起点 0.05 s 和 2.07 s（“浙江农林大学”和“生日快乐”）。

这一步没有单独的脚本文件。下面是完整的处理代码，在 vo 目录下用 ~/Movies/ZAFU/.venv 的 Python 运行（b4.wav 是 vo/bday/b4.mp3 解码出的 48 kHz 单声道 WAV）：

```python
import json, numpy as np, soundfile as sf, librosa
from scipy.signal import firwin2, fftconvolve
SR = 48000
full, sr = sf.read('audition/zwt_full.wav', dtype='float32'); full = full.mean(1) if full.ndim > 1 else full
tim = json.load(open('audition/zwt_timing.json')); b, _ = sf.read('bday/b4.wav', dtype='float32')
def ltas(x):
    S = np.abs(librosa.stft(x, n_fft=4096, hop_length=1024)) ** 2; e = S.sum(0); keep = e > np.percentile(e, 50)
    return 10 * np.log10(S[:, keep].mean(1) + 1e-12)
ref = np.concatenate([full[int(tim[u]['start'] * SR): int((tim[u]['start'] + tim[u]['dur']) * SR)] for u in ('u16', 'u17', 'u18')])
A, B = ltas(ref), ltas(b[int(1.6 * SR):int(5.2 * SR)]); f = np.fft.rfftfreq(4096, 1 / SR)
d = A - B; d -= np.average(d[(f > 300) & (f < 3000)])
sm = np.zeros_like(d)
for i, fi in enumerate(f):
    if fi < 20: continue
    m = (f > fi / 2 ** (1 / 6)) & (f < fi * 2 ** (1 / 6)); sm[i] = d[m].mean()
sm = 0.7 * np.clip(np.where((f > 80) & (f < 12000), sm, 0), -4, 4)
fir = firwin2(2047, f / (SR / 2), 10 ** (sm / 20)); bq = fftconvolve(b, fir, 'same').astype(np.float32)
seg = bq[int(1.62 * SR): int(5.45 * SR)]
n1, n2 = int(0.02 * SR), int(0.25 * SR)
seg = seg * np.concatenate([np.linspace(0, 1, n1), np.ones(len(seg) - n1 - n2), np.linspace(1, 0, n2)]).astype(np.float32)
start = len(full) / SR + 0.5
out = np.concatenate([full, np.zeros(int(0.5 * SR), np.float32), seg, np.zeros(int(0.5 * SR), np.float32)])
sf.write('audition/zwt2_full.wav', out, SR, subtype='FLOAT')
tim2 = dict(tim); tim2['u18'] = {'start': round(start, 3), 'dur': round(len(seg) / SR, 3), 'asr': '浙江农林大学 生日快乐', 'clauses': [0.05, 2.07], 'src': 'vo/bday/b4.mp3 (EQ matched to the closing lines of zwt11, 70%)'}
json.dump(tim2, open('audition/zwt2_timing.json', 'w'), ensure_ascii=False, indent=1)
```

### 4.2 CLAP“耳朵”（clap_tool.py）

- 模型：LAION CLAP laion/larger_clap_general（经 transformers 加载，Apple 芯片上用 MPS）。
- embed_audio()：音频 → 单位向量（不足 1 s 的片段循环补到 1 s）；embed_text()：文字 → 单位向量；余弦相似度即点积。
- score(片段, 标签表)：概率 = softmax(20 × 余弦)。

### 4.3 扫描方法（记录在 audio/v3/LIB_SCAN_v19.md）

1. **切窗**：床类素材 2 s 窗、1 s 步长，关键文件再用 1 s 窗、0.5 s 步长细扫；一次性音效 2 s 窗 0.5 s 步长，并用起音检测把每一下单独切出来嵌入。
2. **先归一再嵌入**：每个窗先归一到 -24 dBFS（dBFS：相对数字满刻度的电平，0 dBFS 是能记录的最大值）RMS（安静文件不归一时 CLAP 的判断会漂；混音里床也都会被推到目标电平，归一更接近实际听感）。5.1 文件按 eng.fold6 同一公式折成单声道。
3. **标签表**（环境类 29 个）：
   - 好：melodious songbirds singing、gentle birdsong in a quiet forest、a blackbird or thrush singing、small birds chirping softly；
   - 坏：a crow cawing、seagulls crying、a rooster or chicken、ducks quacking or geese honking、a parrot or jungle bird screeching、a loud harsh bird squawk、an owl hooting、dog barking、traffic or engine、people talking、electrical hum 等；
   - 中性：风、流水、湖水、树叶、昆虫、静音等。
   - 一次性音效另用 27 个标签：好（玻璃风铃、水滴入静水、轻柔纸声、柔和气流、颂钵……）与坏（刺耳 whoosh、卡通音效、游戏音效、失真、科幻电子音、门铃、教堂钟……）。“廉价感” = 卡通 + 游戏 + 失真 + 科幻四项之和。
4. **校准**：先用已知文件定阈值：Bird Crow 有乌鸦的窗 crow 0.42 到 0.48，Dog Bark Small 0.82 到 0.91，Bird Rooster 0.65 到 0.89。判定：2 s 窗 crow ≥ 0.12、1 s 窗 ≥ 0.15 记为可疑；“鹦鹉 + 刺耳尖叫 + 猴叫”三项之和 ≥ 0.40 记为偏尖。
5. **频谱图人工复核**：所有可疑窗都看频谱图。乌鸦的特征是 1 到 4 kHz 的粗糙谐波堆叠，每声约 0.2 s，约 0.6 s 一声连叫。
6. **底噪与哼声**：测窗内外底噪（50 ms 块 RMS 的第 10 百分位）、50/60/100/120/150/180 Hz 的哼声峰。
7. **音高与 D 调**：起音后 30 ms 起取 0.6 到 0.8 s 做 FFT 找峰，给出音名、音分，以及移到最近 D 大调音级所需的变速比 speed = 2^(半音/12)。

成片用到的音效库素材（第 4.5 节）都从这份报告推荐的素材里选出。

## 6. 8D 双耳

### 6.1 双耳渲染引擎（eng.py 的 bin 布局 + spat）

- **HRTF**：spat 是一个 Swift 命令行程序（spat.swift），用 macOS 的 AVAudioEngine 离线渲染模式，每个声源一个 AVAudioPlayerNode，接到 AVAudioEnvironmentNode，renderingAlgorithm 设为 .HRTFHQ（Apple 自带的高质量 HRTF），输出类型为耳机。引擎调用时关闭距离衰减（rolloff 0）和自带混响，距离与混响都由 eng.py 自己处理。声源位置每 0.04 s 一个关键帧，渲染时每 1024 个采样更新一次位置。
- **方向增强（BIN_EQ）**：一个通用人头的 HRTF 前后、上下的区别偏弱，所以按 Blauert 的方向频带在 STFT 上逐帧加一层均衡，跟着移动的声源变化：
  - 在前方：4 kHz +3、450 Hz +1.5、1.1 kHz -2、11 kHz -2（单位 dB，乘 BIN_EQ）；
  - 在后方：1.1 kHz +3、11 kHz +3、4 kHz -3、450 Hz -1.5；
  - 在上方：8 kHz +4、4 kHz -2；
  - 在下方：6.5 kHz 耳廓凹陷 -5、10 kHz 以上 -2。
  - 音效与环境声用 BIN_EQ = 1.9（设计命令里设定）；配乐与人声的房间声用默认 1.6。
- **早期反射**：每个点声源按所在房间的类型加几条早期反射（地面、侧面、身后……），把声音从头里“拿出来”，给出身后的空间。例如森林类：地面 4 ms -7 dB，两侧 17 ms 与 23 ms -15 dB，身后 31 ms -13 dB，后上方 44 ms -16 dB；山谷类有 45 到 95 ms 的远反射；厅堂类 6 到 30 ms。Hangar One 不加早期反射。
- **床的全包围**：立体声床的左右两半各是一个三维声源；环境床再复制一份到头顶（仰角 50°，-5 dB，去相关、250 Hz 高通；水声类不放头顶）；地面类（水、溪、草、雨……）再放一份到下方（仰角 -35°，-6 dB，9 kHz 低通）。去相关用 43 ms 的随机相位全通滤波，避免复制品与原声梳状干涉。
- **场景混响**：每个房间的混响解码到 12 个方向（水平每 45° 一个，加仰角 45° 的四个），身后的方向多 2 dB。
- **低频**：设了 LFE 发送的对象（例如第 5.6 节的低频托底），其 90 Hz 以下部分另外不经 HRTF、直接加到两耳（在 LFE 发送量上再降 3 dB）。

### 7.2 人声链（每一句单独处理）

人声保持配音原有的音色：只做去口水音、去齿音、句内平衡和 polish() 里的轻度音色修正，不做额外提亮，不压换气声。每句按以下顺序处理：

1. **切句**：按 zwt2_timing.json 的 start 和 dur 从 zwt2_full.wav 截出一句（单声道）。
2. **高通**：80 Hz，2 阶 Butterworth。
3. **去口水音 declick()，连做两遍**：
   - 把 2.5 kHz 以上的频段分出来，算 1.5 ms、8 ms、30 ms 三种窗长的 RMS；
   - “咔嗒” = 1.5 ms 的能量比 30 ms 周围高 9 dB 以上、比 8 ms 周围高 4 dB 以上，并且持续不超过 4 ms（比辅音的爆破短，辅音不碰）；
   - 在字里：只减掉这 5 ms 内的高频部分（升余弦窗）；
   - 在停顿里（比该句 98 百分位电平低 22 dB 以上）：整个 5 ms 压低 20 dB。
4. **polish()**：
   - 去齿音：在 5.5 kHz 用 4 阶 Butterworth（零相位）分出高频带；用 4 ms 包络比较高频带与整体的电平，高频带超过“整体 - 9 dB”时，按超出量的 0.6 倍压低高频带，增益再平滑 2 ms；
   - 句内平衡器：pedalboard Compressor，阈值 = 该句 RMS 电平 - 3 dB，2:1，起音 20 ms，释放 250 ms，让一句里每个字的电平接近；
   - 轻度音色：280 Hz -1.5 dB（Q 1.0），3.4 kHz +1.5 dB（Q 0.8），10 kHz 以上高架 +1 dB（Q 0.7）。
5. **响度归一**：每句（复制成双声道测量）用 pyloudnorm 测积分响度，增益到 -22 LUFS（短于 0.5 s 的按 -30 LUFS 计）。
6. **峰值因数控制**：前视限幅器的门限设在 -22 + 11 = -11 dBFS（辅音峰值不超过该句响度 11 dB，通常只在最硬的辅音上动 1 到 3 dB），然后再归一到 -22 LUFS；这一对操作做两遍。每句最后都在同一个电平上。
7. **首尾淡变**：开头 30 ms 正弦平方淡入，结尾 80 ms 余弦平方淡出，房间底噪不再硬切。
8. **放置**：放到 cues.json 给的时刻；若与上一句的间隔小于 0.25 s 就往后推（本片 18 句都没有被推）。

### 7.3 背景（配乐 + 音效 + 环境声）

立体声版和双耳版各算一遍，参数相同：

1. **配乐基准电平**：配乐整体归一到 -27 LUFS（响的段落大约比人声低 6 LU）。
2. **说话时避让（duck）**：人声包络按 10 ms 帧算，高于 -42 dBFS 算“在说话”，前后各保持 0.25 s（跨过字间空隙），起音 0.22 s、释放 0.9 s 平滑。配乐让 DUCK_MX = 8 dB，音效和环境声让 DUCK_FX = 6 dB。
3. **最后一句放松**：从 RELAX_T - 0.3 = 105.65 s 到 105.95 s，配乐的避让从 8 dB 过渡到 8 × 0.5 = 4 dB，让全奏和弦起来。
4. **频段让位（MIDCARVE）**：说话时把配乐的 0.8 到 3.5 kHz（2 阶带通，零相位）按同一包络再压 3 dB，音乐保持饱满，又不盖住字。
5. **人声与背景的最小间距（GAP）**：对每一句，测这句时间段里人声与背景（配乐 + 音效 + 环境）的积分响度差；如果小于 10 LU（最后一句：起点不早于 RELAX_T - 2.5 = 103.45 s 的句子用 GAP_END = 7 LU），就把背景压低差额，0.35 s 渐入、0.8 s 渐出。人声本身不动。
6. **慢推子（LEVELER）**：用 mix_v8.leveler() 在整体混音上找峰值会撞到限幅器的地方：按 10 ms 一块算出把峰值压到 -1 + 1.5 = +0.5 dBFS 以内所需的增益（其余 1.5 dB 留给限幅器），前后保持 0.5 s，0.6 s 汉宁窗平滑，最多 4 dB。这个增益只乘在背景上，人声保持同一电平。
7. **整体增益**：总增益迭代 3 次（每次经过 -1 dBFS 限幅器后重测），使整片积分响度到 TARGET = -16 LUFS。
8. **限幅与收尾**：-1 dBFS 前视限幅器（本片实际增益衰减 0.0 dB，没有动作）；最后 2.0 s 线性淡出。
