# 01 文案、配音与时间表

这部片子的时间是从声音开始定的：先有一条真人配音，切成 18 句；每句放到它要落的画面上；镜头表、字幕、刻字、片尾的高潮点，全部跟着这 18 句的真实开口时间走。这一章按流程顺序讲五件事：

1. 旁白全文，以及它在屏幕上的写法；
2. 配音干声怎样整理、切句，结尾一句怎样补录、挑选、匹配音色；
3. 每句放在片中的哪一秒，以及每句的清理和统一响度；
4. 字幕怎样按配音里真实的停顿对时；
5. 镜头表 `work/v16k/edit18.py` 的结构，以及全片 27 个镜头、26 处接缝（其中 20 处是转场）的完整时间表。

路径约定同[第 0 章](00_制作环境与工具链.md)：工程根目录是 `~/Movies/ZAFU2`，下文写相对路径。

## 1.3 配音干声的准备

### 1.3.1 输入

| 文件 | 内容 | 规格 |
|---|---|---|
| `vo/zwt/zwt11.mp3` | 配音员录的整段旁白（u01 到 u17，末尾另有一句成片不用的结尾句“浙江农林大学，欢迎你”） | MP3，44.1 kHz，单声道，192 kbps，103.13 秒 |
| `vo/bday/b1.mp3` 到 `b6.mp3` | 结尾句“浙江农林大学，生日快乐”的 6 段补录 | MP3，48 kHz，单声道，192 kbps，5.3 到 6.9 秒 |

录音是干声：没有混响、没有配乐，句间停顿里只有很低的房间底噪。

### 1.3.2 转成 48 kHz WAV，检查是不是干声

在 `vo/zwt` 目录里：

```bash
ffmpeg -v error -y -i zwt11.mp3 -ar 48000 zwt11.wav
```

得到 `zwt11.wav`（48 kHz，16 位，单声道）。然后量几段停顿和一段语音的电平（RMS，均方根电平，单位 dBFS，0 dBFS 是数字满幅），以及整段的响度（LUFS，按人耳感知加权的响度单位，ITU-R BS.1770）：

| 测量 | 结果 |
|---|---|
| 句间停顿（3.9 到 5.4 秒、10.4 到 11.2 秒、14.6 到 15.8 秒等 7 处） | -62 到 -73 dBFS |
| 语音（0.5 到 3 秒） | -39.4 dBFS |
| 整段响度 / 峰值 | -33.4 LUFS / -10.2 dBFS |

停顿里的底噪比语音低 23 到 34 dB，没有混响尾巴，可以直接按能量切句。录音末尾 102.5 秒以后是一段 -45 dBFS 的杂音，切句时排除（见 1.3.4 对 u18 的处理）。

### 1.3.3 whisper 转写：拿到每句的边界和逐字时间

用 whisper-large-v3-turbo 的 MLX 版本转写，打开逐字时间，用 `initial_prompt` 告诉它片中的专有名词（避免把校名、地名写错）。在 whisper 环境里、`vo/zwt` 目录下运行（完整代码见本章附录 A）：

- 模型：`mlx-community/whisper-large-v3-turbo`
- 参数：`language='zh'`，`word_timestamps=True`，`initial_prompt='浙江农林大学 天目林学院 浙江林学院 钱王故里 天目山 求真敬业'`
- 输出：`vo/zwt/zwt11_asr.json`（whisper 的原始结果：`text`、`segments`、每段的 `words`）

whisper 给出 28 个分段。0 到 25 段是 18 句旁白（有的句子被分成两到三段），26、27 段是录音末尾杂音上的幻听，不用。分段和句子的对应关系：

| 句 | whisper 分段 | 句 | whisper 分段 |
|---|---|---|---|
| u01 到 u06 | 0 到 5（各一段） | u12 | 14、15 |
| u07 | 6、7、8 | u13 | 16、17 |
| u08、u09、u10 | 9、10、11 | u14 | 18、19 |
| u11 | 12、13 | u15 | 20 |
| | | u16 | 21、22 |
| | | u17 | 23、24 |
| | | u18（录音里那句不用的结尾句） | 25 |

whisper 的识别文字会有同音错字（“根深夜貌”“朔果”“学餐天地”“托局”），这不影响：whisper 在这里只提供**句子边界**和**逐字时间的先验**，屏幕上的字一律用官方文案。另外，whisper 的逐字时间整体偏早约 0.35 秒，所以后面所有“开口时间”都以能量测量为准。

### 1.3.4 按能量切句

切句的规则（附录 B 是完整代码，在声音环境里运行）：

1. **能量曲线**：对 `zwt11.wav` 每 10 毫秒算一次 RMS，换成 dB，再做 5 帧（50 毫秒）滑动平均。
2. **句与句的边界**：在“上一句最后一个字的结束时间 - 0.35 秒”到“下一句第一个字的开始时间 + 0.35 秒”之间，找能量最低的那 10 毫秒，作为两句的分界。这样分界一定落在真正的停顿里（实测所有分界处都在 -75 dB 左右的底噪上，只有录音开头 u01 之前是 -44 dB）。
3. **每句的语音范围**：在两条分界之间，能量高于 -60 dB 的第一帧和最后一帧就是这句话的起止。u18 的右边界额外限制在最后一个字结束后 0.6 秒，把录音末尾的杂音挡在外面。
4. **切点**：每句从“语音开始前 0.05 秒”切到“语音结束后 0.25 秒”（不越过分界）。所以每个切出来的句子里，开口都在第 0.05 秒（u01 例外：它的切点就是录音开头）。

输出三个文件：

| 文件 | 内容 |
|---|---|
| `vo/audition/zwt_timing.json` | 每句 `start`（在录音里的切点，秒）、`dur`（切出的长度）、`asr`（whisper 文字，只作核对）、`clauses`（每个 whisper 分段相对切点的开始时间） |
| `vo/zwt/zwt_words.json` | 每句的逐字时间 `[[字, 开始, 结束], ...]`，时间相对这句的切点 |
| `vo/audition/zwt_full.wav` | 整段录音的 48 kHz WAV（混音时按 `start`、`dur` 从里面截取每句） |

切句结果（u18 在 1.3.5 换成补录后的值）：

|---|---|---|---|---|---|
| u01 | 0.00 | 3.98 | u10 | 47.30 | 3.49 |

### 1.3.5 结尾句：补录、挑选、音色匹配

结尾句是单独补录的，6 段内容相同，都是“浙江农林大学，生日快乐”。处理分四步。

**第 1 步：转码和测响度。** 在 `vo/bday` 里把每段转成 48 kHz 单声道 32 位浮点 WAV，再用 ffmpeg 的 ebur128 测响度和真峰值（dBTP，包括采样点之间的峰值）：

```bash
for k in 1 2 3 4 5 6; do ffmpeg -v error -y -i b$k.mp3 -ar 48000 -ac 1 -c:a pcm_f32le b$k.wav; done
```

| 段 | 时长（秒） | 响度（LUFS） | 真峰值（dBTP） |
|---|---|---|---|
| b1 | 5.32 | -37.5 | -18.3 |
| b2 | 6.72 | -35.7 | -15.6 |
| b3 | 5.43 | -37.0 | -20.7 |
| b4 | 6.90 | -34.5 | -11.9 |
| b5 | 6.65 | -33.1 | -11.7 |
| b6 | 5.50 | -31.5 | -11.4 |

**第 2 步：转写核对内容。** 6 段都重采样到 16 kHz 后用同一个 whisper 模型转写（`initial_prompt='浙江农林大学，生日快乐'`，`condition_on_previous_text=False`），确认每段都是这十个字、没有错读，逐字时间存入 `vo/bday/asr.json`（附录 C）。

**第 3 步：按语气挑一段。** 用 librosa 的 pyin 测基频（60 到 400 Hz），用能量找出两个短语的起止，用 MFCC（梅尔频率倒谱系数，描述音色的一组特征）的余弦相似度比较音色，参照是同一条录音里那句不用的结尾句（同一位配音员、同样位置的收尾语气；中位基频 164 Hz，p10 到 p90 为 115 到 240 Hz）：

| 段 | 语音长度（秒） | 中位基频（Hz） | 前半句 / 后半句中位基频（Hz） | 信噪比（dB） | 与正片音色相似度 |
|---|---|---|---|---|---|
| b1 | 3.30 | 127 | 124 / 190 | 42 | 0.999 |
| b2 | 3.75 | 135 | 135 / 135 | 43 | 0.999 |
| b3 | 3.31 | 182 | 120 / 228 | 42 | 0.999 |
| **b4** | **3.41** | **176** | **134 / 221** | **44** | **0.999** |
| b5 | 4.03 | 160 | 153 / 215 | 46 | 0.994 |
| b6 | 3.45 | 199 | 172 / 246 | 47 | 0.989 |

挑选规则：语气要和正片的收尾最接近，同时“生日快乐”要明显扬起。b2 前后一样平，b6 起伏最大、最激动，b4 的中位基频 176 Hz 最接近参照句的 164 Hz，后半句从 134 Hz 扬到 221 Hz，音色相似度 0.999，所以用 b4。6 段不叠在一起用：同一个人念同一句话叠 6 遍，听起来是相位抵消的怪声，不像合唱。附录 D 的代码同时写出一个试听用的对比文件 `vo/bday/对比_原结尾加6段.wav`（参照句加 6 段，各自归一到 -20 LUFS，间隔 1 秒），它不进成片。

**第 4 步：音色匹配并接进旁白整轨**（附录 D）：

1. 参照：录音里的最后三句（u16、u17 和那句不用的结尾句）拼在一起；对象：b4 的 1.6 到 5.2 秒（只取语音）。
2. 两者各算长时平均频谱（4096 点 FFT，跳 1024 点，只用能量高于中位数的帧），相减得到差值，并以 300 到 3000 Hz 的平均差为 0 点（只比音色，不比音量）。
3. 差值按 1/3 倍频程平滑，只在 80 Hz 到 12 kHz 内生效，限制在 ±4 dB，再乘 0.7（匹配 70%，保留补录本身的一点状态）。
4. 用 `scipy.signal.firwin2` 设计 2047 阶线性相位 FIR 滤波器，对整段 b4 做卷积。实际得到的校正量：

| 频率 | 100 Hz | 200 Hz | 400 Hz | 800 Hz | 1.6 kHz | 3.2 kHz | 6.4 kHz | 10 kHz |
|---|---|---|---|---|---|---|---|---|
| 校正（dB） | -2.8 | -2.7 | -2.0 | +2.8 | -1.2 | +0.3 | -2.6 | -1.5 |

5. 切出这一句：b4 里能量测得的开口在 1.67 秒，最后一个字在 5.08 秒结束，所以从 1.62 秒切到 5.45 秒（同样是开口前 0.05 秒），开头 20 毫秒淡入，结尾 250 毫秒淡出。
6. 接到整轨后面：`zwt_full.wav` 后面加 0.5 秒静音，接上这一句，再加 0.5 秒静音，写成 `vo/audition/zwt2_full.wav`（48 kHz，32 位浮点，单声道，107.96 秒）。
7. 写 `vo/audition/zwt2_timing.json`：u01 到 u17 与 `zwt_timing.json` 相同，u18 改为 `start` 103.631、`dur` 3.83、`clauses` [0.05, 2.07]（“浙江农林大学”在切点后 0.05 秒开口，“生日快乐”在切点后 2.07 秒开口）。整轨里那句不用的结尾句音频还在，但没有任何一句引用它。

混音时用 `--voice zwt2`，就是读 `zwt2_full.wav` 和 `zwt2_timing.json`。

### 1.4.1 CUE_ONSET：全片时间的起点

## 1.5 每句的清理与统一响度

旁白轨在混音脚本 `audio/v3/mix_final.py` 里生成（声音环境）。和旁白有关的部分如下，配乐、音效的避让与总响度见[第 7 章](07_声音.md)。

### 1.5.1 对每一句做的处理（按顺序）

1. **截取**：按 `zwt2_timing.json` 的 `start`、`dur` 从 `zwt2_full.wav` 截出这一句（第 153 行）。
2. **高通**：80 Hz 二阶 Butterworth，去掉低频隆隆声（第 154 行）。
3. **去口水音，做两遍**（`declick()`，第 112 行）：在 2.5 kHz 以上的频带里找 1 到 3 毫秒的短促尖峰（1.5 毫秒窗的电平比 30 毫秒窗高 9 dB 以上、比 8 毫秒窗高 4 dB 以上），持续超过 4 毫秒的不算（那是辅音）。尖峰在字里时，只在 5 毫秒的汉宁窗内减掉它的高频部分；在停顿里时，整个 5 毫秒压低 20 dB。全片共修补 105 处，对人声本身的改变约 -32 dB 以下（逐句测量，最大 -31.9 dB，中位 -38.3 dB）。
4. **轻度润色**（`polish()`，第 39 行）：
   - 齿音：在 5.5 kHz 分频，高频带比整体高出 -9 dB 以上的部分，按超出量的 0.6 倍压下去；
   - 平衡字与字的音量：压缩器阈值 = 这句的 RMS 电平 - 3 dB，比例 2:1，启动 20 毫秒，释放 250 毫秒；
   - 音色：280 Hz -1.5 dB（Q 1.0），3.4 kHz +1.5 dB（Q 0.8），10 kHz 以上高架 +1 dB（Q 0.7）。
   不变调、不变速。
5. **统一响度**：用 pyloudnorm 测这句的综合响度，增益调到 **-22 LUFS**（第 160 行）。每句都一样响。
6. **控制峰值**：峰值限制器的上限 = -22 + 11 = -11 dBFS（辅音峰值最多比这句的响度高 11 dB，4 倍过采样、4 毫秒前瞻、150 毫秒释放），之后再调回 -22 LUFS，重复两遍（第 165 到 166 行）。一般只在最硬的辅音上起 1 到 3 dB 作用。
7. **首尾淡变**：开头 30 毫秒、结尾 80 毫秒的正弦平方淡入淡出，避免房间底噪在句首句尾硬切（第 167 到 169 行）。
8. **放上旁白轨**：放在 `cues.json` 给出的秒数；若会压到上一句，则推后到上一句结束 0.25 秒之后（第 150 行和第 170 行，本片没有触发）。

立体声版里旁白是居中的单声道，两个声道各乘 0.707，不加混响（第 174 行）；8D 双耳版用同一条干声，只在后面垫一层很轻的厅堂反射（0.12 倍），人声不做空间移动（第 188 行）。

与旁白有关的混音参数（完整命令见[第 7 章](07_声音.md)）：`--voice zwt2`、`VOICE_POLISH=4`（先两遍去口水音，再润色）、`SEG_FADE=1`（首尾淡变）、`CREST` 默认 11、`--end 110.0`，输出 `audio/v3/out/v23/stereo/DX.wav` 和 `audio/v3/out/v23/binaural/DX.wav`。

## 1.6 字幕对时

### 1.6.1 为什么按短语而不是按字

这位配音员念得慢，三声字的音量几乎和换气一样低，逐字的时间测不准；但他的**停顿**非常清楚。所以字幕的做法是：每句按标点切成短语，每个短语的起点放在配音“从停顿里出来”的那一刻，字幕以短语为单位整体浮现。

### 1.6.2 align_chunks.py：测出每个短语的开口时间

脚本 `work/v18/align_chunks.py`（画面环境）：

```bash
.venv_ai/bin/python work/v18/align_chunks.py
```

它导入 `edit18.py` 取得 `CUE_ONSET` 和字幕文本，读旁白分轨 `audio/v3/out/v18/stereo/DX.wav`（每句已经按 `cues.json` 放在片中位置上，所以测出的直接就是片中时间；这条分轨里 u01 到 u17 的切句和位置与成片完全相同），输出 `work/v18/chunks.json`。步骤：

1. **文本切短语**：每句的全文（多条字幕用“，”连起来；u01 用问句，u12 用“在这里，我们博览古今，我们学参天地”）在 `，。、,.！？? ` 和空格处切开。例如 u02 切成“1958年”“它落在了钱王故里”“天目山下”三段。
2. **能量曲线**：旁白重采样到 16 kHz，做 STFT（短时傅里叶变换；400 点窗即 25 毫秒，跳 10 毫秒，512 点 FFT），只取 150 到 4000 Hz 的能量，换成 dB，3 帧平滑。以全片 98 百分位为参考 ref：高于 ref - 18 dB 是“说话”，低于 ref - 24 dB 是“安静”（换气和底噪都在说话线以下）。
3. **句子的起止**：从 `CUE_ONSET - 0.15` 秒向后找第一帧“说话”，再往前退到这次能量上升的脚下（前一帧比这一帧低 0.8 dB 以上、且高于 ref - 45 dB 时继续退）。句子结束在下一句开口前 0.1 秒之内的最后一帧“说话”，再加 0.04 秒。
4. **句内的停顿**：句子范围内，从一帧“安静”开始、到下一帧“说话”为止，长度至少 0.12 秒的段落都算停顿。
5. **停顿对标点**：句子里有几个标点，就要选几个停顿。先按字数比例算出每个标点“应该”落在的时间，再在所有停顿组合里选一组，使“停顿结束时间与应在时间之差 / 0.6 - 停顿长度 / 0.3”的总和最小（离得近、停得长的优先）。停顿的结束就是下一个短语的开始，停顿的开始就是上一个短语的结束；最后一个短语结束在句尾。句内的停顿少于标点数时，改为整句按字数比例分配各短语的起点（每个短语结束在下一个短语开始前 0.15 秒）。全片只有 u12 走了这条路（“在这里，我们博览古今，我们学参天地”句内没有两处 0.12 秒以上的停顿），而 u12 不出底部字幕，只决定竖排“博览古今”“学参天地”逐字出现的时间。
6. **短语内的逐字时间**：一个短语有 m 个字、起止为 a、b，第 i 个字的时间 = a + (b - a - 0.18) x i / m（给只能逐字出现的文字用，例如竖排问句）。

输出格式：`{句: [[短语, 开始, 结束, [每个字的时间]], ...]}`。例如：

```json
"u12": [["在这里", 59.58, 60.3, [59.58, 59.76, 59.94]],
        ["我们博览古今", 60.45, 62.04, [60.45, 60.685, 60.92, 61.155, 61.39, 61.625]],
        ["我们学参天地", 62.19, 63.93, [62.19, 62.45, 62.71, 62.97, 63.23, 63.49]]]
```

注意：whisper 在这一步不参与。whisper 决定的是句子边界（1.3.4），短语的开口时间全部来自能量。

### 1.6.3 edit18.py 怎样用 chunks.json

1. **替换逐字时间**（第 61 到 68 行）：读入 `chunks.json`，把每句的逐字时间表 `C.WT[u]['words']` 换成“一字一项”的形式 `[字, 这个字的时间, 下一个字的时间]`。之后所有按配音出现的文字（竖排问句、竖排“博览古今”“学参天地”、校训刻字的时间）都从这里取时间。
2. **找短语里的字**（第 75 到 86 行，`phrase_times()`）：在一句的全部字里找和目标短语最匹配的位置（允许 whisper 认错个别字，比如把“学参”认成“学餐”），返回每个字的时间。
3. **生成字幕**（第 936 到 956 行，`subtitles18()`）：
   - 按每句第一个短语的开口时间排序，逐条字幕处理；字幕里的“，”“、”显示为一个空格，标点后的字开始一个新短语，按顺序消耗 `chunks.json` 里这一句的短语；
   - **一个短语在它开口前 0.08 秒整体浮现**，短语内的字间隔 30 毫秒依次升起，每个字用 0.42 秒从一条看不见的基线下升起来（ease-out 三次曲线，升起高度为字号的 0.55 倍）；
   - **一条字幕的离场时间** = min(最后一个短语结束 + 0.5 秒, 下一条字幕出现 - 0.3 秒)，但不早于最后一个字出现后 0.6 秒；离场时用 0.25 秒淡出（`InkCaption18`，第 926 行）。所以同一时刻屏幕上只有一条字幕。
   - 样式：水平居中，顶边 y = 962（距底边 118 像素），Noto Serif SC 40 像素、字重 500，墨色 (40, 33, 26)；每个字后面垫一圈宣纸色 (0.95, 0.925, 0.86) 的柔光（字形膨胀 7x7 像素后高斯模糊，最高不透明度 0.62），深浅画面上都读得清（`edit17.py` 的 `InkCaption`）。

## 1.8 本章的检查清单

| 检查 | 方法 | 标准 |
|---|---|---|
| 配音是干声 | 量句间停顿的 RMS | -62 到 -73 dBFS，没有混响尾巴 |
| 切点都在停顿里 | 切句脚本打印每个分界处的能量 | 都在约 -75 dB 的底噪上 |
| 结尾句的内容 | whisper 逐字转写 6 段补录 | 十个字齐全，无错读 |
| 结尾句的语气和音色 | pyin 基频、MFCC 相似度、长时平均频谱 | 选 b4；音色校正以录音最后三句为参照，限制在 ±4 dB 以内，只校正 70% |
| 两句不重叠 | 混音脚本的 0.25 秒保护 | 未触发 |
| 每句一样响 | pyloudnorm 逐句测量 | 每句 -22 LUFS |
| 去口水音不伤人声 | 逐句比较处理前后的差值能量，比较长时频谱 | 差值约 -32 dB 以下，频谱差不到 0.1 dB |
| 字幕和开口同步 | `align_chunks.py` 打印每句的短语起止；对照能量曲线 | 每个短语在开口前 0.08 秒出现；同一时刻只有一条字幕 |
| 高潮对点 | 核对“生日快乐”的开口、配乐第 131 拍、`Title19.T_BURST` | 都在 106.0 秒 |

### B. 按能量切句（声音环境，在 `vo/zwt` 目录下）

```python
import json, numpy as np, soundfile as sf
r = json.load(open('zwt11_asr.json')); segs = r['segments']
y, sr = sf.read('zwt11.wav'); h = sr // 100
env = np.array([np.sqrt(np.mean(y[i:i + h] ** 2) + 1e-12) for i in range(0, len(y) - h, h)]); edb = 20 * np.log10(env)
sm = np.convolve(edb, np.ones(5) / 5, 'same')
groups = {'u01': [0], 'u02': [1], 'u03': [2], 'u04': [3], 'u05': [4], 'u06': [5], 'u07': [6, 7, 8], 'u08': [9], 'u09': [10], 'u10': [11],
          'u11': [12, 13], 'u12': [14, 15], 'u13': [16, 17], 'u14': [18, 19], 'u15': [20], 'u16': [21, 22], 'u17': [23, 24], 'u18': [25]}
us = list(groups); thr = -60.0
# boundaries between consecutive lines: the quietest 10 ms between the previous line's last word and this line's first word
bounds = [0.0]
for u, v in zip(us, us[1:]):
    a = segs[groups[u][-1]]['words'][-1]['end'] - 0.35; b = segs[groups[v][0]]['words'][0]['start'] + 0.35
    i0, i1 = int(a * 100), int(b * 100); k = i0 + int(np.argmin(sm[i0:i1])); bounds.append(k / 100)
bounds.append(len(y) / sr)
timing = {}
for j, u in enumerate(us):
    lo, hi = bounds[j], bounds[j + 1]
    if u == 'u18': hi = min(hi, segs[25]['words'][-1]['end'] + 0.6)
    k = np.nonzero(sm[int(lo * 100):int(hi * 100)] > thr)[0]
    a = lo + k[0] / 100; b = lo + k[-1] / 100
    s0 = max(lo, a - 0.05); e0 = min(hi, b + 0.25)
    timing[u] = {'start': round(s0, 3), 'dur': round(e0 - s0, 3), 'asr': ''.join(w['word'] for i in groups[u] for w in segs[i]['words']).strip()}
    timing[u]['clauses'] = [round(segs[i]['words'][0]['start'] - s0, 3) for i in groups[u]]
words = {u: [[w['word'].strip(), round(w['start'] - timing[u]['start'], 3), round(w['end'] - timing[u]['start'], 3)] for i in groups[u] for w in segs[i]['words']] for u in us}
json.dump(timing, open('../audition/zwt_timing.json', 'w'), ensure_ascii=False, indent=1)
json.dump(words, open('zwt_words.json', 'w'), ensure_ascii=False, indent=1)
sf.write('../audition/zwt_full.wav', y.astype(np.float32), sr)
```

### D. 结尾句音色匹配并接进旁白整轨（声音环境，在 `vo` 目录下）

```python
import json, numpy as np, soundfile as sf, librosa
from scipy.signal import firwin2, fftconvolve
SR = 48000
full, sr = sf.read('audition/zwt_full.wav', dtype='float32'); full = full.mean(1) if full.ndim > 1 else full
tim = json.load(open('audition/zwt_timing.json')); b, _ = sf.read('bday/b4.wav', dtype='float32')
def ltas(x):
    S = np.abs(librosa.stft(x, n_fft=4096, hop_length=1024)) ** 2; e = S.sum(0); keep = e > np.percentile(e, 50)
    return 10 * np.log10(S[:, keep].mean(1) + 1e-12)
ref = np.concatenate([full[int(tim[u]['start'] * SR): int((tim[u]['start'] + tim[u]['dur']) * SR)] for u in ('u16', 'u17', 'u18')])
A, B = ltas(ref), ltas(b[int(1.6 * SR):int(5.2 * SR)]); f = np.fft.rfftfreq(4096, 1 / SR)
d = A - B; d -= np.average(d[(f > 300) & (f < 3000)])
sm = np.zeros_like(d)
for i, fi in enumerate(f):
    if fi < 20: continue
    m = (f > fi / 2 ** (1 / 6)) & (f < fi * 2 ** (1 / 6)); sm[i] = d[m].mean()
sm = 0.7 * np.clip(np.where((f > 80) & (f < 12000), sm, 0), -4, 4)
print(' '.join(f'{fc}:{sm[np.argmin(abs(f - fc))]:+.1f}' for fc in (100, 200, 400, 800, 1600, 3200, 6400, 10000)))
fir = firwin2(2047, f / (SR / 2), 10 ** (sm / 20)); bq = fftconvolve(b, fir, 'same').astype(np.float32)
seg = bq[int(1.62 * SR): int(5.45 * SR)]
n1, n2 = int(0.02 * SR), int(0.25 * SR)
seg = seg * np.concatenate([np.linspace(0, 1, n1), np.ones(len(seg) - n1 - n2), np.linspace(1, 0, n2)]).astype(np.float32)
start = len(full) / SR + 0.5
out = np.concatenate([full, np.zeros(int(0.5 * SR), np.float32), seg, np.zeros(int(0.5 * SR), np.float32)])
sf.write('audition/zwt2_full.wav', out, SR, subtype='FLOAT')
tim2 = dict(tim); tim2['u18'] = {'start': round(start, 3), 'dur': round(len(seg) / SR, 3), 'asr': '浙江农林大学 生日快乐', 'clauses': [0.05, 2.07], 'src': 'vo/bday/b4.mp3 (EQ matched to the closing lines of zwt11, 70%)'}
json.dump(tim2, open('audition/zwt2_timing.json', 'w'), ensure_ascii=False, indent=1)
# an audition file: old ending, then the six new takes, each normalised, 1 s apart
import pyloudnorm as pyln
mt = pyln.Meter(SR); parts = []
old = full[int(tim['u18']['start'] * SR): int((tim['u18']['start'] + tim['u18']['dur']) * SR)]
for x in [old] + [sf.read(f'bday/b{k}.wav', dtype='float32')[0] for k in range(1, 7)]:
    x = x * 10 ** ((-20 - mt.integrated_loudness(x.astype(np.float64))) / 20); parts += [x.astype(np.float32), np.zeros(SR, np.float32)]
sf.write('bday/对比_原结尾加6段.wav', np.concatenate(parts), SR, subtype='PCM_24')
```
