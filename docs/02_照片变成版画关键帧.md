# 02 照片变成版画关键帧

《活的版画》里的每一个画面，最初都是一张"关键帧"：一张 16:9 的江南水印木刻版画（墨、石青、石绿、赭石四色，印在宣纸上）。关键帧有两种用法：

1. **直接上屏**：作为静帧镜头整张匀速推移（今天的东湖校门、木化石、森林、一山一水、校训石、研究图版），或作为"一草一木"拼贴里的卡片。
2. **做 AI 视频的首帧和尾帧**：交给 LibTV（Seedance 2.5）生成动态镜头（[第 3 章](03_AI视频_Seedance.md)）。首尾两张都是同一风格的版画，AI 只负责中间的运动。

本章一步一步说明这些关键帧怎样做出来：收集真实照片，裁切与清理，代码先排版式，Codex 完成版画，统一色彩，最后检查。

整条链路由 AI 编程助手 Claude Code 在 MacBook Pro（Apple M3 Max，128 GB）上执行：写脚本、运行脚本、调用 Codex CLI 生成版画、逐张检查。

**两条贯穿全章的规则**

- **只改画风，不改内容**。凡是出现校园建筑、校门、湖岸、山脊和校史的画面，构图都来自一张真实照片；Codex 只能把它"重印"成版画，不能挪动、增删任何建筑，不能扩画。
- **不出现人物，不编造场景**。人、车、路牌、横幅在重印时一并去掉；照片上本来就有的真实题字（校门石上的"浙江农林大学"、石柱上的"浙江省天目林学院"、门牌"浙江林学院"、校训石的书法）逐字保留。只有不涉及具体地点和校史的植物、天空母题（翅果、幼苗、大槭树、金色云海、年轮木片、银杏叶）允许由 Codex 按风格锚点新画构图。

以下命令都在 `~/Movies/ZAFU2` 下运行。画面相关的 Python 用工程里的 `.venv_ai`（OpenCV 4.11.0、NumPy、SciPy、Pillow、scikit-image、PyTorch、transformers、simple-lama-inpainting），网页抓取用工程根目录下的 `.venv`（Python 3.11，requests、Pillow），Codex 批处理用系统 `python3`。

### 2.1.2 命令

抓校友总会四个栏目（已抓过的文章自动跳过，按 SHA1 去重，短边小于 400 像素的图丢掉）：

```bash
.venv/bin/python tools/crawl_xyzh.py
```

按关键词收集学校官网、图书馆网站等参考照（每个主题 30 张，结果和来源页写进 `ref/web/bing/index.json`）：

```bash
.venv/bin/python tools/bing_images.py --n 30
```

把用到的校园实拍视频抽成帧序列（JPEG 质量 2，宽度最大 4096，原帧率；每段视频抽到 `footage/` 下的一个文件夹）：

```bash
bash tools/extract_footage.sh
```

### 2.1.3 取舍规则

- 只用图注或来源能证明是本校的照片；只有编号、没有说明的照片不用。
- 老校门的年代以学校自己的资料为准（校友总会图注、通讯社视频字幕）。片中不标年份签。
- 网络照片和指导老师提供的照片版权归原作者和学校，只作为 Codex 重印的依据，仓库里只发布描述和来源页，不发布照片本身。校园实拍视频也不随仓库发布。

### 2.2.2 清理：人、车、路牌、远处高楼

成片关键帧的清理分两种：

1. **在重印时一并清理（绝大多数）**。去人、去车、去路牌写进同一条 Codex 指令（2.4），不单独修图。例如：
   - K18_gate_donghu：去掉所有汽车、电动车、行人、交通标志、横幅、旗子和右侧广告牌（广告牌位置补成树）；
   - K_S1_first：去掉左侧面包车和后面的小汽车，用照片里延续的碎石地、树和楼基补上；
   - K_S1_last：去掉左下角的小人影；
   - T1_tianmu_ink：去掉山脊上的两座通信塔和小房子；
   - T1_lawn_golden：去掉路灯和小指示牌。
2. **用 LaMa 局部修补（只有风格锚点 1）**。LaMa 是一种图像补全模型，按遮罩把挖掉的区域补成周围的样子。风格锚点 1 是东湖图书馆的版画（Codex 作业 `v15_test.json` 的 `v15_H3_woodblock`，裁 16:9 缩到 1280×720 存为 `libtv_jobs/refs/T2_library_woodblock_1280x720.png`），远山脚下有一片高层住宅。因为它会作为风格参考出现在几乎所有作业里，先用 `work/v16k/clean_h3.py` 把它去掉：
   - 遮罩：在框 `(226, 170)` 到 `(402, 201)` 内取亮度 V > 175 且饱和度 S < 70 的像素（白色楼面），5×5 闭运算、7×7 膨胀，再加上楼群底座一行 `[186:207, 224:300]`；
   - 只在裁块 `(100, 60)` 到 `(612, 316)` 上跑 LaMa（simple-lama-inpainting），**只把遮罩内的像素贴回**，其余像素一个不动；
   - 输出 `libtv_jobs/refs/K_ai2_library_first_clean_1280x720.png`，同时打印改动像素数和遮罩像素数，并输出 3 倍放大的前后对比 `work/v16k/_h3_clean_check.png`。

```bash
.venv_ai/bin/python work/v16k/clean_h3.py
```

老照片**不做超分修复**，裁切缩放后直接交给 Codex 重印。LaMa 只用在 `clean_h3.py` 这一处。

## 2.3 第三步：代码先排版式（交给 Codex 的 Image 1）

只给 Codex 一张照片、让它"把照片改成版画"时，它会按自己的理解重新构图。所以先用代码从真实照片算出一张**粗版式**：每条边都在照片里真实边缘的位置上，颜色已经分成四块印版。Codex 拿到的 Image 1 是这张版式，Image 2 才是照片（只用来认出每块形状是什么），它就只补刻版质感，不再重新构图。

### 2.3.1 深度图

`tools/depth.py` 用 Depth Anything V2 Large（Hugging Face `depth-anything/Depth-Anything-V2-Large-hf`，在 Apple MPS 上运行）算相对深度：

- 工作分辨率：长边 1036 像素（14 的倍数），双三次插值回原尺寸；
- 归一化：取 0.5% 和 99.5% 分位数拉到 0 到 1（1 = 最近）；
- 输出 16 位 PNG `<名字>_d.png`，另存一份 float16 的 `_d.bin` 和尺寸 `_d.json`。

```bash
.venv_ai/bin/python tools/depth.py work/v18/real/gate.png work/v18/real/forest.png work/v18/real/petrified.png --out work/v18/real/depth
```

### 2.3.2 版式：tools/woodblock.py

成片所有带版式的关键帧，Image 1 都由 `tools/woodblock.py` 生成。输入是 1920×1080 的照片和它的视差图，输出 `woodblock.png`。处理分 9 步（`sc = 高度 / 1080`）：

| 步骤 | 做什么 | 参数 |
|---|---|---|
| 1 简化成可印的大块 | 缩到一半，连续两次均值漂移，放大回原尺寸，再做保边滤波 | `pyrMeanShiftFiltering(10·sc, 22)`、`(6·sc, 16)`；有 ximgproc 时用 `jointBilateralFilter(9, 25, 5)`，本机 OpenCV 4.11.0 没有 ximgproc，走 `bilateralFilter(9, 25, 5)` |
| 2 颜色聚类 | 特征 = Lab（L×1.0，a×1.6，b×1.6）+ 视差×60，让远山和近树分开 | k-means，k = 18，随机抽 120000 个像素，k-means++，4 次尝试，60 次迭代或 eps 0.2；随机种子 1958；标签图 5×5 中值滤波 |
| 3 每块一个印色 | 每个聚类的平均色用非负最小二乘分解成四块印版的浓度，再量化成刻版的几个色阶 | 颜料（相对宣纸 0.935/0.905/0.835）：墨 0.17/0.155/0.14，石绿 0.50/0.66/0.52，石青 0.42/0.55/0.68，赭石 0.86/0.60/0.36；正则 0.06；色阶 0、0.35、0.7、1.05、1.5 |
| 4 块内明暗 | 块内浓淡跟随真实光线，但压缩（水印木刻的擦色） | 亮度低通 σ = 18·sc；`shade = clip(1 + 1.4 × (块均值 − 局部亮度), 0.75, 1.35)`；印版边缘模糊 σ 0.7·sc，边缘积色 `+0.9 × (p − blur(p, 5·sc))` |
| 5 留白 | 远山（视差 < 0.16）从山脊往下渐隐成雾；天空（视差 < 0.035 且在上 25%）留成宣纸 | 远山渐隐 `1 − 0.55 × clip(距离 / 110·sc)^1.3` |
| 6 刀痕 | 植被区（石绿浓度 > 0.3 且不是远山）沿局部轮廓方向刻短刀痕，露出纸白 | 网格步长 9·sc，每格 45% 概率下刀，长 4 到 11 像素，线宽 1.6；方向取结构张量（σ 6 与 10）；刀痕处石绿、墨、赭石减 75% |
| 7 木纹与错版 | 每块印版加木纹，再整体错开 1 到 2 像素 | 木纹角度 0.02/−0.04/0.05/0.0，周期 38/26/44/31 像素，`× (0.80 + 0.32·g)`；错版：墨 (0, 0)，石绿 (1.5, −1.0)，石青 (−1.2, 1.0)，赭石 (1.0, 1.4) |
| 8 叠印 | 在宣纸纹理 `data/v14/paper.png` 上按透射率逐版相乘 | `out = 纸 × Π exp(d_k × ln(颜料_k / 纸))` |
| 9 主版刻线 | 在聚类边界里颜色反差大的地方刻墨线，白色建筑再加细节线；线条随机断开，像刀尖跳起 | 边界 Lab 反差 > 26，连通长度 ≥ 30·sc；建筑细节用 Canny 边缘检测 (40, 110)；断线阈值 0.47；墨线强度 0.82 |


```bash

```

它做的事：

1. `--par N`：N 个作业并行（不写时为 4）；`--only` 只跑指定的 id；**已存在的输出直接跳过**（要重新生成某张时，先把旧图移走）。
2. 每个作业在自己的工作目录 `codex/work/<id>/` 里运行，命令是：
   `codex exec --skip-git-repo-check -s workspace-write -c model_reasoning_effort="low" -i <参考图1> -i <参考图2> ... -- <提示词>`，
   参考图按顺序就是提示词里的 Image 1、Image 2……；超时 900 秒；全部输出写进 `run.log`。
3. 提示词由四段拼成：
   - 开头固定："Use your built-in image generation tool to make exactly one image. Do not write code and do not use the CLI fallback."
   - 每张参考图的用途：`Image 1: <labels[0]> Image 2: <labels[1]> ...`（没有 labels 时：只有一张参考图写 "Image 1 is a REAL photograph used as the reference."，多张时每张写 "Image n: real reference photograph."）；
   - 作业自己的 `prompt`；
   - 固定尾句：普通作业接 `COMMON`（不要任何文字、字母、汉字、标志、水印、招牌、字幕、边框；不要扭曲融化的形状，建筑保持笔直、干净、正确的线条）；`keep_text: true` 的作业改接 `COMMON_TEXT`（不新增任何文字，**照片里已有的刻字原样保留**）；再接 "Aspect ratio <aspect>, highest resolution the tool allows."；`transparent: true` 时要求真实透明通道；最后要求把生成的 PNG 拷到当前目录、命名为 `<id>.png`。
4. 成功后把图拷到 `codex/out/<id>.png`，把作业本身原样存成 `codex/out/<id>.json`（记录参考图和提示词），并在 `codex/out/<批次>.log` 记一行"时间 id 状态 耗时"（成功时状态为 ok）。单张耗时 52 到 290 秒。


（参数 A、B、C、D 分别写出 `codex/jobs/v16_KA.json` 到 `v16_KD.json`。）

所有作业遵守同样的规则：

1. **只改画风，内容以照片为准**：`KEEP` 一段要求画布、取景和每栋建筑、山脊、岸线、道路、桥、树团的位置大小不变，不裁、不放大、不扩画、不倾斜、不增删建筑。老照片作业更严："Image 1 is a REAL historical photograph: keep EXACTLY its composition, camera, horizon, every building, pillar, gate, window, roof line and tree in the same place and proportion. Do not add, move or redesign anything."
2. **参考图分工写清楚**：版式"fixes the exact composition and every outline"；照片"only to understand what each shape is"；风格锚点"do not copy its content or composition"。
3. **风格锚点固定**：v16 系列一律带三张锚点（风格锚点 1 东湖图书馆版画、T1_lawn_golden、T1_swans）；指导老师照片的三张带锚点 1 和 T1_lawn_golden；年代关键帧用 T1_tianmu_ink（墨版）或锚点 1 作纸张和刀法参考；东湖两张用 K_S6_last 和 K_S5_last。
4. **光向统一**：太阳在画外左上方，低角度金色侧逆光，影子落向右下。
5. **不出现人物、车辆、文字、印章、签名**（`CLEAN` 加 `COMMON`）。
6. **真实题字原样保留**：`keep_text: true`，指令里写明保留哪几个字、什么颜色。校训石例外：石面先让 Codex 留空（"the front face of the boulder is smooth and completely BLANK"），书法另做：把校训石照片上四个字的区域放大到 1720×520（`work/v16k/real/motto_glyph_crop.png`），作业 K_motto_glyphs（`v17_motto.json`，3:2，keep_text）只做描摹："trace these four characters EXACTLY as they are carved, as solid pure black brush calligraphy on a pure white background"，不许换字体、不许增删笔画；描好的四个字拆成四张遮罩、记下它们在原照片上的坐标，存为 `work/v16k/motto_glyphs.npy`，由代码在原位刻入（[第 4 章](04_代码镜头竹林与three.js.md)）。
7. **不编造场景**：凡是校园和校史画面都有照片依据。由施工照片推导出的"落成"画面（K_S2_last）和"二十年后"画面（K_S7_last）只在 AI 运动中短暂出现，不标年份；推导时机位、轮廓、高度、屋顶线必须与照片一致。
8. **给字幕留位置**：需要竖排字的画面在指令里写"leave the upper third calm for text"（K_ai5、K_aiG）。

## 2.6 统一色彩：墨、石青、石绿、赭石

成片的色彩统一**在出图时完成**，不靠后期调色把风格硬拉到一起。规则是：每批关键帧生成后拼成对比图并排检查，风格不一致的那一张重新生成。具体靠四件事：

1. **同一组风格锚点**：所有作业都带同样的锚点图（2.4.3 第 3 条），配同一段 `STYLE` 和 `LIGHT` 文字。
2. **套色随年代递进**（年代关键帧）：

| 年代 | 印版 | 关键帧 |
|---|---|---|
| 天目林学院时期 | 只用松烟墨 | K_S1_first、K_S1_last、K_S2_last |
| 八十年代初"浙江林学院" | 墨 + 一块赭石（墙、土、树干） | K_S3_last |
| 东湖原址与工地 | 雾中低饱和：赭石、土褐、淡石青；工地加石绿网、赭红塔吊细线 | K_E_P2_2000、K_E_P14_2001 |
| 2004 年新图书馆 | 墨、赭石、石绿、石青 | K_S6_last |
| 今天 | 全彩，加银杏金，金色侧逆光 | K_S7_last、K18_*、其余校园关键帧 |

3. **只缩放，不改色**：Codex 原图 1672×941，代码镜头读入时用 LANCZOS 缩到 1920×1080（`work/v16k/scenes.py` 的 `load()`；`work/v18/K18_*.png`、`work/v16k/K_research_samara_plate_1080.png` 也只是同样的缩放，与原图逐像素一致）；给 LibTV 的参考图用 LANCZOS 缩到 1280×720，放进 `libtv_jobs/refs/`（参考图不高于视频输出分辨率 720p）。关键帧、导出脚本 `work/v16k/export18.py` 和达芬奇时间线都不套用调色 LUT（颜色查找表）。
4. **代码镜头的纸和竹林的调色**：代码镜头里的纸都来自同一张宣纸底图 `data/v14/paper.png`，纸色归一到 `PAPER`（2.3.4）。唯一需要单独调色的是不出自 Codex 的 CG 竹林，用 `work/v18/bamboo_look.py` 的渐变映射压进同一色系（[第 4 章](04_代码镜头竹林与three.js.md)）。达芬奇 V5 轨还有一层 4K 宣纸纹理（正片叠底、不透明度 35%，`work/v16k/build_resolve.py`），因为 Resolve 导入静帧的默认长度是 5 秒，它在成片里只覆盖 0 到 5.0 秒（[第 8 章](08_达芬奇装配输出与检查.md)）。

## 2.9 怎么检查

每一步都有检查，检查图都留在工程里。

| 检查 | 方法 | 看哪里 / 结果文件 |
|---|---|---|
| 版式对位 | woodblock.py 自带：两张图各自取结构边缘（半分辨率，双边滤波 9/40/7，均值漂移 8/18，σ 1.5 模糊后 Canny 30/70，连通长度 ≥ 25），算"照片边缘落在版式边缘 3 像素内的比例"（召回）和反过来的比例（精确） | `lay/<名字>/overlap.json`、`pair.jpg`（蓝、红、黑三色边缘叠加） |
